# GPU Studio

Сайт для генерации видео и фото на одном общем GPU в Higgsfield.

- Регистрация и вход.
- Сервер запускается кнопкой «Запустить сервер» или сам, когда приходит первый промт.
- Пользователь видит загрузку: аренда GPU → загрузка модели → генерация.
- Все задачи идут через одну видеокарту; если людей много, показывается очередь.
- Если 60 секунд нет новых запросов, GPU выключается и снова запускается при следующем запросе.

## Запуск на компьютере (Windows / Mac / Linux)
1. Установите [Node.js 20+](https://nodejs.org).
2. Скачайте папку `gpu-studio`.
3. Запустите **`start.bat`** (Windows) или **`./start.sh`** (Mac/Linux).
4. При первом запуске откроется вход в Higgsfield, см. раздел ниже. Потом сайт будет на **http://localhost:3000**.

Всё ставится и настраивается само: зависимости, файл `.env` со случайным секретом, токен Higgsfield.
Тест без аренды GPU: `npm run mock`.

## Запуск на сервере (VPS)
```bash
git clone https://github.com/a1x10/project3 && cd project3/gpu-studio
./start.sh
```
Или через Docker:
```bash
cp .env.example .env    # впишите SESSION_SECRET
docker compose run --rm gpu-studio node connect.js   # вход в Higgsfield, один раз
docker compose up -d
```
Сайт будет на порту 3000. Для домена и HTTPS поставьте перед ним nginx или Caddy.

## Подключение Higgsfield (`npm run connect`)
Скрипт выводит ссылку. Откройте её и войдите в Higgsfield.
- Если сайт работает на этом же компьютере, вход подхватится сам.
- Если сайт на удалённом сервере, браузер покажет ошибку `127.0.0.1`. Скопируйте адрес из адресной строки и вставьте его в терминал.

Токен сохраняется в `data/higgsfield.json` и обновляется автоматически. Никому не передавайте этот файл.

## Важно
- Все генерации оплачиваются **вашими** кредитами Higgsfield: GPU стоит 98 кредитов в час, пока он включён.
- При остановке сайта (Ctrl+C) GPU выключается. Если процесс упал, при следующем запуске сайт сам выключит оставшийся GPU. На стороне Higgsfield дополнительно стоит автопауза через 5 минут.
- Запрещены промты с несовершеннолетними, дипфейки и откровенный контент с реальными людьми. Higgsfield также применяет свою модерацию.
- Отладка ответов Higgsfield: `DEBUG_HF=1 npm start`.
