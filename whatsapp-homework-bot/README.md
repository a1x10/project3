# 📚 WhatsApp-бот домашних заданий (BilimClass + ИИ Groq)

Бот сидит в WhatsApp-группе класса и работает 24/7:

- **После уроков сам проверяет дневник и присылает новые ДЗ.** Бот смотрит в расписании **BilimClass** (bilimclass.kz), когда закончился последний урок, и через 15 минут скачивает свежий дневник на каждый день недели вперёд. В группу уходят только задания, которые выставили с прошлой проверки (🆕 новое, ✏️ изменено), плюс короткое напоминание, что сдавать завтра. Уже отправленное бот не повторяет.
- **Только свежие данные.** Рассылка и проверки каждый раз скачивают дневник заново. Если BilimClass не отвечает, бот не подсовывает старые данные, а повторит попытку позже.
- **Задания, выставленные днём, бот копит до рассылки после уроков**, чтобы не спамить. Задания на сегодня присылает сразу. Если учитель добавил ДЗ вечером, после рассылки, бот пришлёт его сразу. Выходные и каникулы пропускает, в воскресенье вечером присылает ДЗ на понедельник.
- **Пересылает файлы**, прикреплённые к ДЗ (PDF, Word, фото).
- **Отвечает на вопросы по домашке с помощью ИИ (Groq).** Сам понимает, что сообщение — вопрос по учёбе («как решить №250?», «что задали по физике?»), и объясняет по шагам. Понимает **фото задания** и **голосовые**. Знает, что задано, потому что видит дневник, и не выдумывает задания.
- Команды: `!дз`, `!дз завтра`, `!дз алгебра`, `!неделя`, `!расписание`, `!файлы`, `!спросить` и другие.
- Для круглосуточной работы: переподключается сам, не теряет сообщения при обрывах связи и перезапусках, рассылку, пропущенную из-за выключения, отправляет после запуска. Есть защита от спама и лимиты на ИИ, админам приходят уведомления о проблемах, а `/health` показывает состояние для мониторинга.

### Как выглядит рассылка после уроков

```
📚 Домашнее задание · Вт 14.10
Проверил дневник BilimClass в 14:35 — данные свежие

🆕 Новые и изменённые задания (2):

Алгебра — на завтра, среду, 15.10 ✏️ изменено
№ 250, 251 (стр. 58)

История — на четверг, 16.10
Параграф 5, ответить на вопросы

📌 Не забудьте на завтра, среду, 15.10:
• Русский язык: Упр. 5

💬 Есть вопрос по заданию? Напишите в чат — помогу разобраться.
```

Самая первая рассылка после подключения содержит все задания на неделю вперёд. Дальше приходит только новое.

## ⚠️ Важно знать заранее

1. **Нужен отдельный номер WhatsApp для бота** (вторая SIM-карта, eSIM или WhatsApp Business на втором номере). Бот подключается как «связанное устройство», как WhatsApp Web, через неофициальную библиотеку [Baileys](https://github.com/WhiskeySockets/Baileys). WhatsApp может заблокировать номер за спам, поэтому не используйте основной номер и не рассылайте сообщения посторонним.
2. **У BilimClass нет официального API.** Бот работает так же, как сайт дневника, через логин и пароль ученика. Если BilimClass изменит свой сайт, бота нужно будет обновить.
3. Логин и пароль хранятся только в файле `.env` на вашем сервере. Не публикуйте этот файл.

## Установка

### 1. Скачать бота на сервер

```bash
git clone https://github.com/a1x10/project3.git
cd project3/whatsapp-homework-bot
```

> Если бот ещё не слит в ветку `main`, клонируйте его ветку: `git clone -b claude/lucid-mendel-7ktxm0 https://github.com/a1x10/project3.git`

### 2. Заполнить настройки

```bash
cp .env.example .env
nano .env
```

Минимум нужно заполнить:

```ini
BILIM_LOGIN=логин_ученика
BILIM_PASSWORD=пароль
GROQ_API_KEY=gsk_...
ADMIN_NUMBERS=77011234567          # ваш номер: вам придут уведомления, вам доступны админ-команды
WA_PAIRING_NUMBER=77001234567      # номер БОТА (для привязки кодом). Можно оставить пустым и привязать по QR
```

Остальные настройки описаны прямо в `.env.example`: когда присылать ДЗ (`DIGEST_MODE`, `DIGEST_DELAY_MINUTES`), на сколько дней вперёд (`DIGEST_DAYS_AHEAD`), режим ИИ, лимиты и т.д.

### 3. Запустить. Вариант А: Docker (рекомендуется)

```bash
# если Docker ещё не установлен:
curl -fsSL https://get.docker.com | sh

docker compose build
docker compose run --rm bot npm run check   # проверка: вход в BilimClass, ДЗ, ключ Groq
docker compose up -d
docker compose logs -f        # здесь появится QR-код или код привязки
```

Бот сам перезапускается после сбоев и перезагрузки сервера (`restart: unless-stopped`). Данные (сессия WhatsApp, состояние) хранятся в Docker-томе `bot-data`.

### 3. Запустить. Вариант Б: Node.js + PM2

```bash
# Node.js 22 (если не установлен)
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs

npm ci --omit=dev
npm run check                 # проверка: вход в BilimClass, ДЗ, ключ Groq
npm start                     # первый запуск вручную, чтобы привязать WhatsApp (Ctrl+C после привязки)

sudo npm i -g pm2
pm2 start ecosystem.config.cjs
pm2 save && pm2 startup       # автозапуск после перезагрузки сервера (выполните команду, которую покажет pm2)
pm2 logs homework-bot         # логи
```

Можно запускать и через systemd: готовый файл лежит в `deploy/homework-bot.service`, инструкция внутри.

### 4. Привязать WhatsApp

На телефоне с номером бота: **WhatsApp → Настройки → Связанные устройства → Привязка устройства**.

- **По коду** (если задан `WA_PAIRING_NUMBER`): в логах появится `КОД ДЛЯ ПРИВЯЗКИ WHATSAPP: ABCD-EFGH`. Нажмите «Привязать по номеру телефона» и введите код.
- **По QR**: отсканируйте QR-код из логов. Если в терминале он отображается плохо, задайте в `.env` `HTTP_TOKEN=длинный_случайный_пароль` и откройте `http://IP-сервера:3000/qr?token=...`. Для этого нужен доступ к порту, подробности ниже.

Привязка нужна один раз: сессия сохраняется в `data/wa-auth`.

### 5. Подключить группу класса

1. Добавьте номер бота в WhatsApp-группу класса.
2. В группе напишите **`!привязать`**. Это может сделать админ группы или номер из `ADMIN_NUMBERS`.
3. Готово: бот ответит, что группа подключена. Проверьте командой `!дз`.

## Команды

| Команда | Что делает |
|---|---|
| `!дз` | ДЗ на ближайший учебный день (до 12:00 в учебный день показывает задания на сегодня) |
| `!дз завтра` · `!дз пт` · `!дз 20.10` | ДЗ на конкретный день |
| `!дз алгебра` | ближайшее ДЗ по предмету (понимает «матем», «англ», «физра» и т.п.) |
| `!неделя` · `!неделя след` | ДЗ на всю неделю |
| `!расписание [день]` | уроки, время, кабинеты |
| `!файлы [день]` | прислать файлы к заданиям |
| `!спросить вопрос` | спросить ИИ напрямую |
| `!помощь` | список команд |

**Для админов:**

| Команда | Что делает |
|---|---|
| `!привязать` / `!отвязать` | присылать или не присылать ДЗ в эту группу |
| `!автоответ вкл/выкл` | ИИ сам отвечает на вопросы в группе (когда выключено, по-прежнему работают `!спросить` и ответ на сообщение бота) |
| `!авторассылка вкл/выкл` | ежедневная рассылка в эту группу |
| `!рассылка` | проверить дневник и прислать новые ДЗ прямо сейчас |
| `!обновить` | проверить дневник на изменения сейчас |
| `!добавить завтра Алгебра: №250-255` | добавить ДЗ вручную (если учитель дал его устно) |
| `!удалить N` | удалить добавленное вручную |
| `!статус` · `!группы` · `!id` | состояние бота (в том числе во сколько сегодня рассылка), список групп, ID чата |

Админы бота: номера из `ADMIN_NUMBERS`, админы WhatsApp-группы класса и сам владелец номера бота (команды, набранные с его телефона).

## Как работает ИИ-помощник

ИИ видит ДЗ из дневника за последние 3 дня и на неделю вперёд, а также расписание ближайших дней и последние сообщения чата. Поэтому на «а что по физике?» он ответит именно про ваше задание.

**Когда бот отвечает** (режим `AI_MODE=smart`):

- если его позвали: `@упоминание`, ответ на его сообщение, обращение «бот, …», `!спросить`, личное сообщение;
- если сообщение похоже на вопрос по учёбе. Сначала срабатывает быстрая проверка по словам, затем лёгкая модель решает, нужно ли отвечать. На болтовню («кто идёт в кино?») и вопросы конкретному человеку («Аня, ты сделала?») бот не отвечает.

**Фото задания:** пришлите фото с вопросом в подписи или ответьте боту на фото. **Голосовые** бот расшифровывает через Whisper и отвечает текстом.

**Стиль** (`AI_STYLE`): `tutor` объясняет по шагам и даёт ответ, `hints` даёт только подсказки, без готовых решений. Сочинения целиком бот не пишет, только помогает с планом и идеями.

**Модели Groq** (бесплатный тариф, октябрь 2026): основная `openai/gpt-oss-120b`, быстрая для фильтра вопросов `openai/gpt-oss-20b`, для фото `qwen/qwen3.8-27b`, для голосовых `whisper-large-v3-turbo`. Если Groq отключит модель, бот автоматически перейдёт на запасную (`GROQ_FALLBACK_MODELS`), а в `.env` можно указать новую.

**Лимиты:** не больше `AI_USER_LIMIT` вопросов от одного человека за `AI_USER_WINDOW_MINUTES` минут и не больше `AI_DAILY_LIMIT` ответов в сутки. Так бесплатный лимит Groq не закончится из-за одного любопытного одноклассника.

## Если что-то не так

| Проблема | Решение |
|---|---|
| `Неправильный логин или пароль` | проверьте `BILIM_LOGIN` / `BILIM_PASSWORD`, войдите с ними на bilimclass.kz. После ошибки бот ждёт 30 минут перед новой попыткой, чтобы аккаунт не заблокировали |
| ДЗ показывается не на тот день | `npm run check` покажет, на какой день попадают задания. Если они стоят на дне, когда их задали, поставьте `HOMEWORK_ATTACHED_TO=assigned` |
| Бот не отвечает в группе | группа не привязана: напишите `!привязать`. Проверьте `!статус` |
| ИИ молчит | не задан или неверный `GROQ_API_KEY` (админу придёт уведомление); проверьте `AI_MODE` и `!автоответ` |
| `сессия открыта в другом месте` | запущены две копии бота с одной сессией. Оставьте одну |
| Бот отвязался от телефона | в логах снова появится QR или код привязки, привяжите заново |
| `HTTP 426` от BilimClass | BilimClass изменил API, бота нужно обновить |
| Рассылка приходит слишком рано (учителя не успевают заполнить дневник) | увеличьте `DIGEST_DELAY_MINUTES`, например до 60 |
| Во сколько будет рассылка сегодня? | команда `!статус` или `npm run check`. Бот также пишет это в лог |
| Не удалось определить школу | укажите `BILIM_SCHOOL_ID` и `BILIM_GROUP_ID` в `.env` |

**Мониторинг:** `curl http://127.0.0.1:3000/health` отвечает `200` (`ok`) или `503` (WhatsApp не на связи больше 10 минут). Этот адрес можно подключить к UptimeRobot или аналогу.

**Открыть QR в браузере с компьютера**, не открывая порт в интернет: `ssh -L 3000:127.0.0.1:3000 user@сервер`, затем `http://localhost:3000/qr?token=...`.

**Обновление бота:**

```bash
git pull
docker compose up -d --build      # или: npm ci --omit=dev && pm2 restart homework-bot
```

**Резервная копия:** папка `data/` (или Docker-том `bot-data`). В ней сессия WhatsApp (`wa-auth`) и состояние бота (`state.json`). Без неё WhatsApp придётся привязывать заново.

```text

  bilimclass/client.js  API BilimClass: вход, повторный вход при 401, повторы при сбоях

  homework/service.js   кэш, «следующий учебный день», поиск изменений, контекст для ИИ
  homework/format.js    оформление сообщений WhatsApp
  ai/groq.js            клиент Groq: повторы, запасные модели, Whisper
  ai/assistant.js       решает, отвечать ли, и формирует ответ (текст, фото, голос)
  whatsapp/connection.js  Baileys: QR/код, переподключение, очередь отправки
  whatsapp/handler.js   входящие сообщения → команды или ИИ
  whatsapp/commands.js  команды
  scheduler.js          рассылка после уроков (время — по расписанию из дневника), только новые ДЗ,
                        проверка дневника днём, догонялка после простоя
  health.js             /health и /qr
tests/                  84 теста (node --test), без сети
```

```bash
npm install
npm test
```

Эндпоинты BilimClass: `POST /api/v2/os/login`, `GET /api/v4/os/clientoffice/diary?schoolId&eduYear&date=ДД.ММ.ГГГГ(пн)&groupId`, `GET /api/v4/os/clientoffice/homeworks/simple-homework/info?homeworkUuid`. Обязательны заголовки `X-Localization`, `X-Mathrix`, `Origin`, иначе сервер отвечает `426`.
