# Vibing AI Studio

Приложение для Windows, которое собирает сайты с помощью ИИ. Вы описываете сайт в чате, модель собирает его в живом превью справа. Дальше его можно править словами («добавь в шапку кнопку») или руками: перетаскивать блоки, менять ширину и порядок. Есть проекты и чаты, история версий, 60 шаблонов и экспорт `index.html`.

## 3D Pro: профессиональные шаблоны с 3D-анимацией

Каждый новый сайт собирается из **14 профессиональных шаблонов** с живыми 3D-сценами на Three.js: галактика частиц, жидкая капля, стеклянный узел, неоновая сетка, кристаллы, световой туннель, ДНК, город, боке, планеты, шёлковые ленты, гироскоп, потоки линий, глобус. Есть анимации при прокрутке, 3D-наклон карточек, счётчики и «магнитные» кнопки.

- **Шаблон выбирает только ИИ.** Пользователь описывает бизнес, а ИИ сам подбирает шаблон под нишу, пишет тексты и подбирает палитру (JSON). Дизайн, вёрстка и 3D собираются движком `src/pro3d/`. Ручного выбора шаблона и галереи в приложении нет.
- **Цвета и шрифты** можно сменить одним кликом на панели над полем ввода, тексты сохраняются, контраст проверяется автоматически.
- **Правки словами** («смени цвета на зелёные», «добавь тарифы», «сделай стиль строже») отправляют ИИ текущий JSON. Он меняет содержимое и при необходимости сам выбирает другой шаблон.

## Аккаунт и ИИ — через ваш сервер Stella Cloud

Студия работает только через сервер [Stella Cloud](../cloud/README.md):

- **Вход через Telegram.** При первом запуске приложение показывает код и открывает бота. Нажмите в чате «Подтвердить вход», и вы в студии. Аккаунт создаётся автоматически, пароли не нужны.
- **Модели.** Все запросы идут на `https://ваш-сервер/v1`. Сервер добавляет системный промпт владельца, считает лимиты тарифа и передаёт запрос в FreeLLMAPI. Ключей провайдеров в приложении нет.
- **Тариф и лимиты** видны в шапке. Кнопка с тарифом открывает аккаунт: там расход за сегодня, ссылки на личный кабинет и, для администратора, на админ-панель сайта.
- Ключ входа хранится в зашифрованном виде через DPAPI Windows (`safeStorage` Electron). Кнопка «Выйти» отзывает его на сервере. Если администратор заблокирует или удалит аккаунт, приложение вернётся к окну входа.

Адрес сервера берётся (по порядку) из: `STELLA_CLOUD_URL`, файла `stella-cloud.json` (`{"url":"https://…"}`) рядом с `.exe` или в папке данных приложения, адреса из `stella-coder login` / установщика (`~/.stella/credentials.json`), значения `VITE_CLOUD_URL`, заданного при сборке. Если адрес не найден, его можно ввести в окне входа.

## Запуск и сборка

```bash
npm install
npm run desktop      # собрать интерфейс и открыть приложение (Electron)
npm run dist:win     # установщик release/VibingAIStudio-Setup-<версия>.exe (собирать на Windows)
```

Чтобы вшить адрес сервера в сборку:

```powershell
$env:VITE_CLOUD_URL="https://ai.example.com"; npm run dist:win
```

Готовый `.exe` положите на сервер (`/data/downloads`). Тогда на сайте появится кнопка «Скачать Studio для Windows».

Режим разработки интерфейса в браузере: `npm run dev` (http://localhost:3000). Адрес сервера вводится в окне входа, сервер разрешает CORS.

## Тесты

```bash
npm test                                   # юнит-тесты: клиент ИИ, вход в облако, движок правок
npm run build && npm run e2e               # Chromium: вход через бота → генерация → правка → перезапуск → блокировка
E2E_ELECTRON=1 npm run e2e                 # то же в настоящем окне Electron (Linux: xvfb-run -a …)
```

e2e запускает настоящий сервер Stella Cloud (`../cloud/server`, нужен `npm ci` там) с фейковыми Telegram Bot API и сервером моделей. Он проверяет, что промпт владельца доходит до модели, что лимиты считаются на сервере и что блокировка в Telegram выкидывает пользователя из приложения. Скриншоты сохраняются в `test-results/`.
