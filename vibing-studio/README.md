# Vibing AI Studio

Конструктор сайтов с ИИ: описываете сайт в чате — модель собирает его в живом превью справа, дальше вы правите его словами («добавь в шапку кнопку») или руками (перетаскивание блоков, ширина, порядок). Проекты и чаты, история версий, 60 шаблонов, экспорт `index.html`, тарифы и админка.

## ИИ: FreeLLMAPI по умолчанию

Основной провайдер — [FreeLLMAPI](https://freellmapi.co): самохостящийся OpenAI-совместимый роутер, который отправляет запрос в одну из сотен бесплатных моделей и сам переключается на другую при лимитах.

Проще всего — общий установщик в корне репозитория (`../install.sh`, на Windows `..\install.cmd`, см. [INSTALL.md](../INSTALL.md)). Он установит и запустит роутер, получит единый ключ и сохранит его в `~/.stella/credentials.json`. Дальше `npm run dev` сам поднимает роутер, а прокси Vite подставляет ключ на стороне сервера — вставлять его в браузере не нужно.

Ручная установка роутера: `curl -fsSL https://freellmapi.co/install.sh | bash`, затем ключ `freellmapi-…` со страницы Keys дашборда вставьте в **AI: FreeLLMAPI** (или задайте `FREELLMAPI_API_KEY`).

Модели: `auto:smart` (по умолчанию — самая сильная доступная), `auto:fast`, `auto` или любой конкретный id из каталога (`qwen/qwen3.8-max:free`, `glm-5.3:free`, …). Под каждым ответом видно, какая модель реально ответила (`auto:smart → groq/llama-3.3-70b-versatile`).

Запросы идут на `/llm/v1/chat/completions`, а dev/preview-сервер Vite проксирует `/llm` на роутер — браузеру не нужен CORS. Роутер на другом адресе:

```bash
FREELLMAPI_URL=http://192.168.1.10:3001 npm run dev
```

Также доступны OpenAI, Anthropic (нативный Messages API), Google Gemini, Qwen, Kimi, локальный сервер и любой OpenAI-совместимый endpoint (Ollama, LM Studio, OpenRouter, vLLM).

## Запуск

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # сборка в dist/
npm run preview      # раздача dist/ с тем же прокси /llm
```

При первом запуске зарегистрируйтесь: **первая учётная запись становится владельцем и администратором** (админка: пользователи, тарифы, ключи активации). Остальные пользователи получают тариф Free; Pro и VIP подключаются ключом активации, который выпускает администратор.

## Тесты

```bash
npm test                                   # юнит-тесты: клиент ИИ, хранилища, движок правок
npm run build && npm run e2e               # браузер: регистрация → ключ → генерация → правка → перезагрузка
```

e2e поднимает `vite preview` и локальный сервер с протоколом FreeLLMAPI, управляет Chromium через Playwright и сохраняет скриншоты в `test-results/`.

## Важно про безопасность

Аккаунты, лимиты, тарифы и ключи активации хранятся **в localStorage браузера**. Пароли хранятся только в виде солёного хеша, а платный тариф нельзя выбрать кнопкой — но любой, кто откроет инструменты разработчика, может изменить свои данные в localStorage. Это подходит для личного использования и демо. Для публичного сервиса с реальными тарифами нужен сервер: регистрация/вход, лимиты и проксирование запросов к ИИ должны выполняться там, а ключи провайдеров не должны попадать в браузер.

Ключи провайдеров, введённые в окне «AI», тоже лежат в localStorage этого браузера. FreeLLMAPI рассчитан на личное использование: не открывайте роутер в интернет.
