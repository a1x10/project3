# Зрение агента GLF.Agent.Vision

Агенту дают только картинку (RGB-байты) и число действий. Ничего про «стены», «ключ», «дверь» или «я» ему не сказано.

## Конвейер (на каждый кадр)
1. **Цветовые классы** (`ColorClusters`): пиксель попадает в ближайший известный цвет (порог 50 по RGB) или создаёт новый класс. Это даёт устойчивость к шуму и независимость от палитры.
2. **Объекты** (`SceneAnalyzer`): связные области одного класса (заливка, 4-связность) → `Blob` с площадью, рамкой и центроидом. Области мельче 4 px отбрасываются.
3. **«Кто я?»** (`AvatarDiscovery`): после каждого действия ищутся объекты, которые сдвинулись жёстко (та же форма, новое место). Класс, который двигается в ответ на разные действия, — аватар. Усреднённые сдвиги — эффект каждого действия, минимальный ненулевой сдвиг — размер шага сетки.
4. **Состояние** (`VisualAgent.Encode`): клетка аватара + битовая маска «какие типы объектов ещё есть на экране». Подобранный ключ и открытая дверь исчезают с экрана, и состояние меняется само.
5. **Планирование**: то же `ModelBasedAgent` (модель мира + оптимистичное любопытство), что и для невизуальной среды.

До опознания аватара агент «бормочет»: сначала по кругу все действия, затем случайные (до 80 шагов).

## Что доказано тестами
- Те же объекты находятся при шуме ±12 на канал.
- Аватар и действия определяются при тайно перемешанных действиях и случайной палитре.
- Побег с экрана на двух разных картах; оптимальный путь с 2-го эпизода.

## Ограничения (честно)
- Сцена — дискретная сетка, видимая целиком; аватар — один жёсткий объект.
- Движение без смены формы; вид сверху, без перспективы и анимации.
- Нет понимания «смысла» вне награды: что дверь открывается ключом, агент узнаёт из опыта, а не из знания о мире.
- Время кадра ~0.2 мс на CPU (в 200 раз медленнее торгового контура): наивный проход по всем пикселям. Ускорение: разность кадров и анализ только изменившихся областей.
- Для реальных игр нужны следующие слои: слежение за многими движущимися объектами, шаблоны спрайтов, частичная наблюдаемость (память), непрерывные действия.
