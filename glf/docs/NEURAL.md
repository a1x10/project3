# GLF.Neural — нейроны, слои, обучение (с нуля, C#)

Ни одной внешней ML-библиотеки: векторизация `System.Numerics.Vector<float>`, обратное распространение написано вручную и проверено численно.

## Нейрон и слой
Нейрон считает `y = f(w·x + b)`. Слой `Dense(in,out)` хранит матрицу W размером `[out, in]`: строка = один нейрон, поэтому `w·x` — один SIMD-проход по непрерывной памяти. Далее `Activation` применяет нелинейность (ReLU, LeakyReLU, Tanh, Sigmoid, GELU, SiLU), без неё слои схлопнулись бы в одну линейную формулу.

## Слои
| Класс | Формула прямого прохода |
|---|---|
| `Dense` | y = x·Wᵀ + b |
| `Activation` | y = f(x) поэлементно |
| `LayerNorm` | y = γ·(x−μ)/√(σ²+ε) + β по признакам каждого образца |
| `Residual` | y = x + F(x), градиент идёт и через обход, и через F |
| `Sequential` | цепочка слоёв; хранит все промежуточные значения для обратного прохода |

## Обучение
1. **Прямой проход**: слои по порядку.
2. **Потеря** (`Loss`): MSE, Huber (устойчива к выбросам цены), BCE по логитам, Softmax-кросс-энтропия. Возвращает значение и dL/dвыхода.
3. **Обратный проход**: каждый слой получает dL/dy и отдаёт dL/dx и градиенты своих параметров (цепное правило). Для Dense: dW = dyᵀ·x, db = Σdy, dx = dy·W.
4. **Оптимизатор** (`Adam`, AdamW): моменты первого и второго порядка, поправка смещения, decoupled weight decay, обрезка градиента по глобальной норме.
5. **Инициализация**: He (√(2/n)) для ReLU-подобных, LeCun (√(1/n)) для остальных, выходной слой стартует малым.

## Проверка корректности
Тесты сравнивают аналитический градиент с численным (центральная разность) по каждому параметру и по входу: Dense, все 6 активаций, LayerNorm, Residual. Плюс: сеть учит XOR, классифицирует 3 кластера, сохранение/загрузка даёт те же выходы, обучение и вывод **не выделяют память**.

## Онлайн-обучение в торговле
`NeuralModel` учится прямо из потока: каждое событие даёт пару (признаки, итог через 10 событий). Пара кладётся в окно повторов (1024), на каждом событии делается один шаг Adam на мини-батче из новой выборки и случайных старых. Входы и цель нормируются бегущими статистиками (`OnlineStandardizer`). Две сети (32-16 и 16 нейронов) соревнуются в ансамбле с линейными гипотезами; вес даёт скользящая ошибка «сначала предсказал, потом учил» (prequential).

## Автоматический вывод формул
`FormulaDiscovery` (разреженная регрессия по библиотеке членов, как в SINDy): подгоняет все кандидаты (x, x², x³, tanh, sin/cos k·x, произведения), отбрасывает малые коэффициенты, пересчитывает оставшиеся, повторяет. Применяется к выходам обученной сети, получается читаемая формула.
Пример (`dotnet run -c Release -- neural fit`): скрытый закон `2·sin(3x1)·x2 + x3² − 0.5·x1·x3`. Сеть, видя только выборки, достигает R²=0.9998 на новых данных. Извлечённая формула: `1.999·sin(3x1)·x2 + 0.999·x3² − 0.499·x1·x3` (R²=0.9999).
Ограничение: найти можно только то, что выразимо словарём членов. Сеть даёт гладкое приближение, а не доказательство формулы.

## Что измерено
- Изолированный тест на взаимодействии (y = 3·a·sign(b) + шум): линейная модель 1.81 (= «ничего не предсказывает»), нейросеть 0.57 при уровне шума 0.50.
- На синтетическом рынке нейросети дают лишь небольшой выигрыш ансамбля (1–2% по RMSE) и не меняют PnL: линейная часть уже объясняет основное. Реальный выигрыш надо проверять на записанных данных.
- Цена: решение растёт с ~0.7 мкс до ~30 мкс (p50) из-за обучения двух сетей на каждом событии, 0 байт в куче. Возможный путь ускорения: обучение в отдельном потоке, подмена весов атомарно.

## Найденная и исправленная ошибка
Ранее линейные гипотезы использовали классический RLS с «забыванием». На длинных прогонах (400k событий) ковариация раскручивалась, и отдельные гипотезы давали RMSE в десятки тысяч тиков, ансамбль спасали только веса. Заменено на взвешенную гребневую регрессию из достаточных статистик (решение Холецкого каждые 4 обновления). Теперь RMSE стабилен на всём прогоне, тест `Ridge_model_stays_bounded...` это страхует.
