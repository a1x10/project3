# Презентация Stella Pocket Rescue

`Stella_Pocket_Rescue.pptx`: 20 слайдов в стиле Apple, примерно на 10 минут. К каждому слайду есть заметки
докладчика с тем, что говорить.

## Анимации
- Между слайдами стоит переход «Трансформация» (Morph). Коробка, телефон и окно консоли плавно перелетают
  со слайда на слайд. Переход работает в PowerPoint 2019, 2021 и Microsoft 365; в более старых версиях
  вместо него будет обычное «Выцветание».
- На каждом слайде элементы появляются по очереди сами, сразу после перехода. Докладчику достаточно
  одного нажатия на слайд.

## Как пересобрать
```
python presentation/assets.py                                   # картинки: устройства, коробка, иконки, фоны
cd presentation && npm install pptxgenjs@3.12.0 && cd ..
NODE_PATH=presentation/node_modules node presentation/build.js  # слайды, заметки и anim.json
python presentation/animate.py                                  # переходы и появление элементов
```
