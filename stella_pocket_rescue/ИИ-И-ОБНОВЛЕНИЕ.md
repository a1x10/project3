# Stella Pocket 2.0 — ИИ, питание, обновление и показ жюри

## Что изменилось

- **ИИ в три уровня.** Есть интернет — отвечает облачный Claude. Нет интернета — локальная модель
  на самой плате. Нет и её — резервный диспетчер по правилам. Коробка сама проверяет, что работает,
  и переключается без участия человека. Сбоящий уровень временно пропускается, попытки повторяются
  всё реже, пока он снова не заработает.
- **Защита от перезагрузок.** Локальный ИИ стартует через 45 секунд после включения, на одном ядре
  и с пониженной частотой процессора. Если плата всё равно перезагрузилась из-за питания, пока он
  работал, коробка это замечает. Две такие перезагрузки за 30 минут — и локальный ИИ выключается сам.
  Облако и резерв при этом продолжают отвечать.
- **Консоль спасателя** показывает, какой ИИ сейчас отвечает, а у каждого ответа — значок «Claude»,
  «локальная» или «резерв».
- **Страница проверки для жюри:** `http://10.42.0.1/verify`.
- **Команда `stella`** умеет всё это настраивать одной строкой (шпаргалка в конце).

## Какой облачный ИИ взять и почему

Рекомендую **Claude API от Anthropic** — поддержка уже встроена в коробку.

Почему именно он:
- хорошо пишет по-русски, коротко и спокойно — то, что нужно диспетчеру;
- строгие правила безопасности: не станет советовать опасное;
- если основная модель откажется отвечать, сервер сам передаст вопрос запасной модели;
- официальная библиотека для Python, коробка использует её напрямую;
- оплата только за использование, без подписки.

**Модель по умолчанию — `claude-opus-5`**, в быстром режиме (короткое обдумывание).
Цена: $5 за миллион входных токенов и $25 за миллион выходных.
Если важнее экономия, переключись на **`claude-haiku-4-5`** ($1 и $5):
`sudo stella ai model claude-haiku-4-5`. Он быстрее и дешевле, но отвечает попроще.

**Сколько это стоит на практике.** Один ответ диспетчера — примерно 1 500 токенов на вход
и 300 на выход (вместе с обдумыванием):

| Модель | Один ответ | $5 хватит примерно на |
|---|---|---|
| claude-opus-5 | ~1,5 цента | ~330 ответов |
| claude-haiku-4-5 | ~0,3 цента | ~1 600 ответов |

Для соревнования и тестов $5 хватит с запасом.

### Как получить ключ

1. Открой **platform.claude.com** (консоль Anthropic) и зарегистрируйся.
2. Раздел **Billing** → пополни баланс: минимум $5, нужна карта Visa или Mastercard,
   которая платит за границу.
3. Раздел **API Keys** → **Create Key** → скопируй ключ. Он начинается с `sk-ant-` и
   показывается один раз.
4. Проверь, что твоя страна есть в списке поддерживаемых
   (страница **Supported countries** на сайте Anthropic). Казахстан, насколько я знаю,
   в нём есть, но список иногда меняется.

Ключ — как пароль от кошелька: никому не показывай, не пиши в чат и не выкладывай на GitHub.

### Как положить ключ в коробку

На плате:
```
sudo stella ai key
```
Вставь ключ (при вводе его не видно — так задумано) и нажми Enter. Затем проверь:
```
sudo stella ai test
```
Команда покажет, какой ИИ ответил, за сколько секунд, и сам ответ.

Ключ вводится только через команду на плате, не через сайт: сеть SOS открытая,
и ключ, переданный через неё, мог бы кто-нибудь перехватить.

**Что уходит в облако:** только текст переписки пострадавшего с диспетчером и краткая сводка
сортировки. Данные телефона, IP-адреса и координаты в облако не отправляются.

## Как дать коробке интернет в поле

Сеть SOS при этом продолжает работать. Пострадавшие интернет не получают: он нужен только самой
коробке, для облачного ИИ.

1. **Телефон по USB (проще всего).** Подключи Android-телефон кабелем к USB платы.
   На телефоне: *Настройки → Сеть → Точка доступа → USB-модем*.
2. **Кабель Ethernet** от любого роутера с интернетом.
3. **4G USB-модем** со своей SIM-картой.

Проверить, появился ли интернет: `sudo stella ai` — строка облака станет «на связи».

## Питание — почему плата перезагружалась

Когда локальная модель считает, процессор берёт много тока. Слабый блок питания или тонкий
длинный провод не выдерживают, напряжение проседает, и плата перезагружается.

**Правильное решение — блок питания 5 В / 3–4 А и короткий толстый USB-C кабель.**

Пока его нет, коробка защищает себя сама:
- `auto` (по умолчанию) — щадящий режим; после двух аварийных перезагрузок локальный ИИ выключается;
- `sudo stella power` — показать режим и сколько было сбоев;
- `sudo stella power normal` — полная мощность (только с хорошим блоком питания);
- `sudo stella power reset` — забыть сбои после замены блока питания.

## Как обновить плату (без мучений)

Домашний Wi‑Fi больше не нужен: обновить можно прямо через сеть SOS.

1. **Дай плате интернет** (телефон по USB — см. выше). Без интернета обновление тоже пройдёт,
   но только файлы программы: облачный ИИ и маленькая модель поставятся при следующем
   обновлении с интернетом.
2. **Ноутбук подключи к Wi‑Fi `SOS-STELLA-RESCUE`.**
3. **В PowerShell на ноутбуке скопируй архив на плату:**
   ```
   cd $HOME\Downloads
   scp stella_pocket_rescue.zip orangepi@10.42.0.1:~
   ```
4. **Зайди на плату и запусти обновление:**
   ```
   ssh orangepi@10.42.0.1
   sudo stella update
   ```
   Пароль спросит сразу, в начале — дальше всё идёт само.
5. **Смотри, как идёт установка:**
   ```
   sudo tail -f /var/log/stella-install.log
   ```
   Выйти из просмотра — Ctrl+C, установка продолжится. Связь по SSH может оборваться, когда
   установщик перезапустит сеть, — это нормально. Подожди 3–5 минут, снова подключись к
   `SOS-STELLA-RESCUE` и зайди на плату.
6. **Проверь:** `sudo stella status`.

Если интернета через телефон нет, можно по-старому, через домашний Wi‑Fi:
`sudo stella home "ИМЯ_WIFI" "ПАРОЛЬ"` → по показанному адресу скопировать архив и зайти по SSH →
`sudo stella update`. После установки плата сама вернётся в режим SOS. Если к домашнему Wi‑Fi
подключиться не удалось, новая команда `stella home` сама возвращает сеть SOS.

## Как показать коробку жюри

1. **Заранее, пока ноутбук ещё в обычной сети,** открой на нём файл `site/verify.html` из архива
   (двойной щелчок) и нажми **F** — полный экран.
2. При жюри подключи ноутбук к Wi‑Fi `SOS-STELLA-RESCUE`. Страница сама заметит коробку
   («Сигнал узла обнаружен») и откроет проверку. Если браузер спросит разрешение на доступ
   к локальной сети — разреши. Вручную: `http://10.42.0.1/verify`.
3. Дальше по шагам:
   - **Приветствие** с 3D-моделью коробки;
   - **PIN спасателя**;
   - **Живая диагностика** — 20 проверок: Wi‑Fi, раздача адресов, перехват DNS, база, сортировка,
     три уровня ИИ, датчик, лампа, вентилятор, температура, память, питание, целостность программы;
   - **Местоположение узла** — можно задать координаты;
   - **Живой ответ ИИ** — пример сообщения пострадавшего и настоящий ответ диспетчера;
   - **Паспорт узла** с печатью.
4. Для репетиции без коробки: `site/verify.html?demo=1` или `http://10.42.0.1/verify?demo=1`.
   В демо-режиме в углу честно горит значок «ДЕМО-РЕЖИМ» — на настоящем показе используй
   обычный режим.

## Сайт настроек и доступ из интернета

### Сайт настроек /admin

На сайте коробки есть страница настроек: состояние, PIN консоли, режим ИИ, питание, имя и канал сети SOS,
домашний Wi-Fi, демо для стенда, журналы, перезапуск, обновление, перезагрузка и выключение.

- Пароль администратора создается при установке. Показать: `sudo stella admin password`,
  новый: `sudo stella admin password new` (все входы на сайте сбросятся).
- Где можно войти: по кабелю или USB (`http://ИМЯ_ПЛАТЫ.local/admin` или по IP), через домен коробки
  по HTTPS, в сети SOS по HTTPS после `stella tls sync`. По открытой сети SOS через простой HTTP вход
  запрещен: пароль там могут подслушать. Если очень нужно: `sudo stella admin wifi on`, потом `off`.
- Ключ Claude, сервер туннеля и домены сайт не меняет, только команда на плате. Так украденный пароль
  не позволит увести коробку на чужой сервер или прочитать ключ.
- Все действия с правами root выполняет помощник `/usr/local/sbin/stella-admin` со строгим списком
  действий. Код в `/opt/stella` теперь принадлежит root, сайт не может его менять.

### Доступ из интернета через свой сервер

Коробка сама держит SSH-туннель до вашего сервера, когда у нее есть интернет (кабель или телефон по USB,
сеть SOS при этом работает). Белый IP не нужен. Нужны сервер и два домена: один для коробки, другой для
рекламного сайта. Подробно по шагам: [server/README.md](server/README.md). Коротко:

```
sudo stella remote key                         # на коробке: ключ коробки
sudo bash server/stella-server.sh install     # на сервере: домены, ключ, сертификат (параметры в server/README.md)
sudo stella remote pair 'STELLA-PAIR строка'   # на коробке: связать
sudo stella remote on                          # включить туннель
sudo stella tls sync                           # HTTPS для доменов и без интернета
```

- Из интернета открывается все: чат, `/verify`, консоль и настройки. Консоль и `/verify` из интернета
  требуют сначала вход администратора, потом PIN. В поле, в сети SOS, консоль по-прежнему только по PIN.
- Обращения из интернета в консоли помечены «через интернет». Выключить чат из интернета:
  `STELLA_REMOTE_CHAT=0` в `/etc/stella/stella.env` и `sudo stella restart`.
- Если коробка не в сети, домен показывает страницу «коробка не в сети».

### Рекламный сайт без интернета

Сайт из папки `site/` ставится на коробку вместе с программой и открывается без интернета:
`http://10.42.0.1/site/`, а в сети SOS еще и по домену сайта. Шрифты и 3D-библиотека лежат в
`site/vendor`. На стенде можно включить демо: `sudo stella demo on` (или кнопка на странице настроек),
тогда при подключении к сети SOS сначала открывается рекламный сайт, а чат остается на `http://10.42.0.1/`.
Демо само выключается через 12 часов и не работает в режиме ЧС.

## Шпаргалка команд

```
sudo stella status            что работает: сеть, службы, ИИ, питание
sudo stella ai                состояние облака, локальной модели и резерва
sudo stella ai key            ввести ключ Claude (ввод скрыт)
sudo stella ai test           проверить, кто и как отвечает
sudo stella ai model claude-haiku-4-5    сменить облачную модель
sudo stella ai mode auto      auto | cloud | local | offline
sudo stella power             режим питания и сбои
sudo stella power reset       забыть сбои питания
sudo stella pin               показать PIN консоли
sudo stella pin new           новый случайный PIN
sudo stella update            обновить из архива stella_pocket_rescue.zip
sudo stella home "WIFI" "ПАРОЛЬ"   домашний Wi‑Fi для обслуживания
sudo stella sos               вернуть сеть SOS
sudo stella logs              журналы
sudo stella admin password    пароль сайта настроек /admin
sudo stella wifi name "ИМЯ"   имя сети SOS (и wifi channel 1-13)
sudo stella remote            удаленный доступ: key, pair, on, off, test
sudo stella tls sync          HTTPS для доменов, в том числе без интернета
sudo stella demo on           демо для стенда на 12 часов
sudo stella update --github   обновиться из GitHub, когда есть интернет
```

Ссылки: пострадавшие `http://10.42.0.1/`, спасатели `http://10.42.0.1/rescuer`,
проверка узла `http://10.42.0.1/verify`, настройки `http://10.42.0.1/admin`,
рекламный сайт `http://10.42.0.1/site/`.
