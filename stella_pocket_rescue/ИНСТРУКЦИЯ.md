# Stella Pocket — установка на Orange Pi 4 LTS с нуля

## Что понадобится
- Orange Pi 4 LTS и блок питания **5 В / 4 А** (обычная зарядка на 2 А не подойдёт)
- microSD-карта от 16 ГБ и картридер
- сетевой кабель (Ethernet) и домашний роутер с интернетом
- компьютер (Windows, macOS или Linux)
- телефон, чтобы в конце проверить Wi-Fi

## Шаг 1. Записать систему на карту
1. Откройте https://www.armbian.com, найдите в поиске **Orange Pi 4 LTS**.
2. Скачайте образ **Debian 12 (Bookworm), Minimal / CLI**. Не Ubuntu и не образ с рабочим столом.
3. Установите **balenaEtcher** (https://etcher.balena.io).
4. В Etcher: «Flash from file» → скачанный образ → ваша карта → «Flash». Ждите окончания.

## Шаг 2. Включить плату
1. Вставьте карту в плату.
2. Подключите плату кабелем к роутеру.
3. Включите питание. Подождите 2–3 минуты.

## Шаг 3. Узнать IP-адрес платы
Зайдите в настройки роутера (обычно http://192.168.0.1 или http://192.168.1.1),
раздел «Подключённые устройства» / «DHCP-клиенты». Ищите имя вроде `orangepi4-lts`.
Запишите адрес, например `192.168.1.50`. Дальше он везде обозначен как `IP_ПЛАТЫ`.

## Шаг 4. Подключиться к плате
**Windows:** нажмите Пуск, наберите `powershell`, откройте.
**macOS / Linux:** откройте «Терминал».

```
ssh root@IP_ПЛАТЫ
```
- На вопрос `Are you sure you want to continue connecting` напишите `yes`.
- Пароль при первом входе: `1234` (при вводе символы не видны — это нормально).
- Armbian попросит придумать новый пароль root и создать пользователя. Сделайте это и запомните пароль.

## Шаг 5. Отправить проект на плату
Откройте **второе** окно PowerShell / Терминала **на компьютере** (не на плате).
Перейдите в папку, где лежит `stella_pocket_rescue.zip` (например, «Загрузки»):

```
cd Downloads
scp stella_pocket_rescue.zip root@IP_ПЛАТЫ:~
```
Введите пароль root. Файл скопируется на плату.

## Шаг 6. Установить
Вернитесь в первое окно (где вы на плате) и вставьте:
```
apt update && apt install -y unzip
unzip -o stella_pocket_rescue.zip
cd stella_pocket_rescue
sudo ./deploy/install.sh
```
- Установка идёт **30–40 минут**: собирается нейросеть и скачивается модель (~1,1 ГБ).
- Если сборка оборвалась со словом `Killed` — не хватило памяти. Запустите ещё раз так:
  `sudo JOBS=1 ./deploy/install.sh`
- В конце появится **PIN спасателя**. Запишите его. Потом его можно посмотреть командой
  `sudo cat /etc/stella/stella.env`
- Если хотите, чтобы на карте спасателя было ваше место, откройте
  `sudo nano /etc/stella/stella.env` и впишите координаты в `STELLA_HUB_LAT` и `STELLA_HUB_LON`
  (сохранить: Ctrl+O, Enter, выйти: Ctrl+X).

## Шаг 7. Перезагрузить
```
sudo reboot
```
Подождите 2 минуты. Модели нужно ещё около минуты, чтобы загрузиться.

## Шаг 8. Проверить
1. **Телефон:** в списке Wi-Fi появится сеть **SOS-STELLA-RESCUE**. Подключитесь —
   чат откроется сам. Если нет, откройте в браузере `http://10.42.0.1/`.
   Телефон может написать «нет подключения к интернету» — так и должно быть, выберите «Оставаться на связи».
2. **Консоль спасателя с компьютера** (плата подключена кабелем к роутеру):
   откройте `http://IP_ПЛАТЫ/rescuer` и введите PIN.
   Или подключите ноутбук к сети SOS-STELLA-RESCUE и откройте `http://10.42.0.1/rescuer`.

## Если что-то не работает
Зайдите на плату по кабелю (`ssh root@IP_ПЛАТЫ`) и выполните:
```
systemctl status stella-app stella-llm hostapd dnsmasq nginx --no-pager
```
Скопируйте вывод целиком и пришлите — по нему видно, что сломалось.

Полезные команды:
- логи сайта: `journalctl -u stella-app -n 50 --no-pager`
- логи Wi-Fi: `journalctl -u hostapd -n 50 --no-pager`
- модель загружена? `curl http://127.0.0.1:8081/health`

**Важно:** после установки Wi-Fi платы превращается в точку доступа, а вход по SSH через Wi-Fi
закрыт специально. Управлять платой можно только по кабелю.

## Как обновить код
Скопируйте новый архив (шаг 5), затем на плате:
```
unzip -o stella_pocket_rescue.zip && cd stella_pocket_rescue && sudo ./deploy/install.sh && sudo reboot
```
Повторный запуск безопасен: уже собранная нейросеть и скачанная модель не качаются заново.
