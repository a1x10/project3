Удаленный доступ

Вход на коробку через ваш сервер и домен, когда у нее есть интернет (кабель или телефон по USB).


        
Подключение к серверу и смена доменов делаются только командой на плате:
          sudo stella remote key, sudo stella remote pair, sudo stella remote on.
