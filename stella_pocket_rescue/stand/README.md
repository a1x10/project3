# Стенд для конкурса «Зерде»

Складной стенд: центр 60×80 см и две боковые створки по 30×80 см.

## Файлы для типографии (папка `out/`)

| Файл | Размер после обреза | Размер с вылетами |
|---|---|---|
| `stand_left_300x800.pdf` | 300×800 мм | 306×806 мм |
| `stand_center_600x800.pdf` | 600×800 мм | 606×806 мм |
| `stand_right_300x800.pdf` | 300×800 мм | 306×806 мм |

`stand_preview.png` показывает, как три панели выглядят рядом.

## Что сказать в типографии

1. Печать в полный цвет, масштаб 100%, не подгонять под размер.
2. Вылеты 3 мм с каждой стороны уже есть в файлах, линия обреза размечена (TrimBox).
3. Материал: самоклеящаяся пленка или фотобумага с накаткой на пенокартон 5 мм. Матовая ламинация меньше бликует.
4. Три панели печатаются отдельно и потом крепятся к основе стенда.

## Как пересобрать

```
pip install qrcode playwright pillow pypdf
python stand/build.py
```

Текст и раскладка лежат в `stand.html`. Скрипт `build.py` делает QR-коды, три PDF и превью. Если текст не помещается на панель или на ней остались заглушки, скрипт об этом напишет.
