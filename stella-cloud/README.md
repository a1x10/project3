# Stella Cloud

Сервер для Stella: агент работает, даже когда компьютер выключен; приложение для телефона; перенос задач ПК ↔ сервер; WhatsApp для агента.

## Установка на сервер (Ubuntu / Debian)

```bash
curl -fsSL https://raw.githubusercontent.com/a1x10/project3/claude/happy-ritchie-vx32ws/stella-cloud/install.sh | sudo bash
```

Скрипт ставит Node.js 22, Antigravity CLI (`agy`), сам сервер (systemd-служба `stella-cloud`) и HTTPS через Caddy.
В конце он печатает адрес (по умолчанию `https://<ip-сервера>.sslip.io`) и **код приглашения**.
Свой домен: `DOMAIN=stella.example.com` перед `bash`. Обновление — та же команда.

Порты 80 и 443 должны быть открыты (для HTTPS-сертификата Let's Encrypt). Если на сервере уже есть nginx — установщик добавит в него отдельный сайт и получит сертификат через certbot, ничего не трогая.

**Свой адрес через DuckDNS** (бесплатно): зарегистрируйтесь на duckdns.org, создайте имя (например `mystella`) и запустите:

```bash
curl -fsSL https://raw.githubusercontent.com/a1x10/project3/claude/happy-ritchie-vx32ws/stella-cloud/install.sh | sudo DUCKDNS=mystella bash
```

Токен DuckDNS установщик спросит скрыто. IP обновляется каждые 5 минут. Адрес станет `https://mystella.duckdns.org`.


## Как пользоваться

1. **Телефон.** Откройте адрес сервера → «Регистрация» (имя, пароль, код приглашения) → «Добавить на главный экран».
   Для каждого аккаунта создаётся отдельный Linux-пользователь `st_<имя>` со своей папкой и своим агентом.
2. **Вход агента в Google** (один раз): «Ещё» → «Открыть терминал агента» → откройте ссылку, войдите, вставьте код.
3. **Компьютер.** Stella → «Облако» (слева внизу) → адрес сервера, имя, пароль.
   Теперь с телефона видно, что делает агент на ПК, можно дать ему задачу и нажать «→ Сервер», чтобы задача продолжилась на сервере (и обратно «→ Компьютер»). На ПК есть кнопка «↗ На сервер».
4. **WhatsApp.** Вкладка WhatsApp → «Подключить по QR-коду» → WhatsApp на телефоне → Связанные устройства.
   - Агент пишет людям **только когда вы просите**: «напиши жене, во сколько ужин» → он находит контакт, пишет в вашем стиле, ответ приходит вам в чат и уведомлением.
   - **Автоответчик** включается отдельно для каждого контакта (переключатель в списке). Не отвечает на вопросы про деньги/встречи/то, чего не знает; не больше 40 ответов в день на контакт; всё пишется в журнал.
   - ⚠️ Это неофициальное подключение (протокол WhatsApp Web, библиотека Baileys). WhatsApp может заблокировать номер за автоматизацию.

## Настройки

`/etc/stella-cloud.env`:

| Переменная | Значение |
|---|---|
| `STELLA_SIGNUP` | `invite` (по коду, по умолчанию), `open`, `closed` |
| `STELLA_INVITE` | код приглашения |
| `STELLA_WA_PROXY` | прокси для WhatsApp, если сервер выходит в интернет только через прокси |

После изменения: `systemctl restart stella-cloud`. Логи: `journalctl -u stella-cloud -f`.

## Проверка работ (СОР, СОЧ, контрольные) по фото

Главная → «📝 Проверить работы»: название, предмет, класс, ключ ответов / критерии, максимальный балл, шкала, сколько страниц в работе, список класса (необязательно).
Загрузите фото листов (камерой, хоть 100+; телефон сжимает их перед отправкой). Агенты проверяют параллельно (`STELLA_GRADING_PARALLEL`, по умолчанию 3):
разбирают почерк (рус/каз/англ), находят фамилию, проверяют каждое задание по ключу, ставят баллы и оценку.
**Неразборчивое не угадывается** — работа помечается «⚠ проверить» с причиной. Учитель может исправить имя, баллы и оценку, перепроверить работу, выгрузить всё в Excel и одной кнопкой отправить агенту на ПК «выставить в BilimClass» (только работы без пометки).

### 🔒 Скрытие ФИО до отправки (включено по умолчанию)
- При загрузке учитель один раз выделяет пальцем место, где на листе пишут ФИО. **Телефон сам** перерисовывает каждое фото: закрашивает эту область чёрным, пишет «Работа №N» и удаляет метаданные фото (EXIF, GPS). Только после этого фото уходит на сервер. Если закрасить не получилось, фото не отправляется.
- Сервер и ИИ видят только «Работа №1, №2…». Агенту отдельно сказано не пытаться прочитать имя, а если модель его всё же вернёт, сервер его стирает.
- Вырезанный кусочек с ФИО, подписанные имена и список класса хранятся **только на этом телефоне** (IndexedDB). «✍ Подписать имена»: под каждым фрагментом с ФИО — поле с подсказками из списка класса.
- Таблица с именами (CSV для Excel) собирается прямо на телефоне. Для «Выставить в BilimClass» список «имя — оценка» (без фото) один раз уходит агенту на ПК: на сайте журнала имена и так есть. Сервер этот список не сохраняет.
- Ограничения: имена есть только на телефоне, где загружали фото (другое устройство покажет «Работа №N»). Если ФИО написано вне выделенной области (на обороте, на полях), оно не закроется, поэтому выделяйте с запасом.

## ⬇ Скачать Stella для Windows с вашего сервера

`https://<ваш-домен>/download` — страница со ссылкой на Stella.exe; файлы: `/download/Stella.exe`, `/download/StellaConference.exe`, `/download/version.json`, `/download/conference.json`.
Установщик кладёт их в `/opt/stella-cloud/downloads` (из `agy-desktop/release`), ночное автообновление (`AUTOUPDATE=1`) обновляет их вместе с сервером.
Stella.exe берёт обновления и «Конференцию» сначала с вашего сервера, GitHub — только запасной вариант.

## 🎥 Конференция (помощник на созвонах)

В Stella.exe слева есть переключатель **«Конференция»**. Он скачивает (с проверкой SHA-256) и запускает **Stella Conference** — изменённую версию [Pluely](https://github.com/iamsrikanthnani/pluely) © Srikanth Nani (GPL-3.0, исходники в `stella-conference/`), уже подключённую к вашему аккаунту и моделям Gemini через сервер Stella (`/api/conf/v1/chat/completions`, `/api/conf/v1/stt`). Всё нужное Stella готовит заранее, в фоне после запуска: скачивает Stella Conference с вашего сервера и, если в Windows нет компонента WebView2, ставит его. Если подготовить не удалось, открывается встроенное окно Stella:
- **живая расшифровка** разговора: «Я» — ваш микрофон, «Собеседник» — звук звонка из любой программы (Zoom, Meet, Teams, Telegram, WhatsApp), Windows-loopback;
- **⚡ Авто:** когда собеседник задаёт вопрос, подсказка «что ответить» появляется сама;
- кнопки **💡 Что ответить**, **❓ Вопросы** (что спросить), **📝 Итоги** (решения, задачи), **📸 Экран** (объяснит слайд, документ или задачу на экране), поле «Спросить Stella»;
- прозрачность окна, пауза; в конце расшифровка и подсказки сохраняются в `<рабочая папка>/Конференции/*.md`.

Работает на самых быстрых моделях Gemini: распознавание — `gemini-flash-lite-latest`, подсказки — `gemini-flash-latest` с потоковым ответом (меняются через `STELLA_CONF_STT_MODEL` и `STELLA_CONF_MODEL`).
Нужен ключ Gemini API на сервере (https://aistudio.google.com/apikey). Добавить его: запустите установщик с `GEMINI=1`, ввод скрыт.
**Или DeepSeek через OpenRouter** (один ключ на всё, https://openrouter.ai/keys): установщик с `OPENROUTER=1`. Тогда ответы — `deepseek/deepseek-v4.1-flash` (понимает и скриншоты), распознавание речи — `google/gemini-3.1-flash-lite` через OpenRouter (DeepSeek звук не понимает). Модели меняются через `STELLA_CONF_OR_MODEL` / `STELLA_CONF_OR_STT_MODEL`; если заданы оба ключа, используется OpenRouter (`STELLA_CONF_PROVIDER=gemini` — вернуть Gemini).
На сервере ничего не сохраняется. Звук и текст уходят в Google Gemini: на бесплатном ключе Google может использовать данные для улучшения моделей, на платном — нет.
Окно видно при показе экрана, оно не прячется от участников. Предупреждайте собеседников, что разговор расшифровывается. Лучше в наушниках, иначе микрофон слышит собеседника из колонок.

## Конфиденциальность — честно

- **Где лежат данные:** аккаунты, чаты, фото работ, WhatsApp-переписка, пароли сервисов — только на вашем сервере. Пароли зашифрованы, каждый аккаунт изолирован в своём контейнере.
- **Что уходит наружу:** чтобы агент «думал», текст задачи и нужные файлы (в т.ч. **фото детских работ** с ответами; ФИО по умолчанию закрашиваются на телефоне ещё до отправки, см. выше) отправляются в модель Google (Antigravity / Gemini). Это не полностью конфиденциально: условия хранения и использования данных зависят от вашего аккаунта Google (личный бесплатный / платный / Workspace / ключ Gemini API платного уровня).
- **Персональные данные детей:** это персональные данные несовершеннолетних (в Казахстане — Закон РК «О персональных данных и их защите»). Перед проверкой работ через ИИ согласуйте это со школой / родителями; для максимальной приватности используйте платный ключ Gemini API (`STELLA_GEMINI_API_KEY`), по условиям которого данные не используются для обучения.
- WhatsApp подключается неофициально; сообщения хранятся только на вашем сервере.

## Автообновление

- **Stella.exe** (с версии 1.2.0) раз в 6 часов проверяет `agy-desktop/release/version.json`, скачивает новую версию в фоне, проверяет SHA-256 и предлагает «Обновить и перезапустить».
- **Телефон** обновляется сам (плашка «Доступна новая версия»).
- **Сервер**: `AUTOUPDATE=1` при установке — каждую ночь ~04:20 подтягивает новую версию и перезапускается (`AUTOUPDATE=0` — выключить).

## Команда агентов (как Manus)

Кнопка **👥** (телефон: новый чат на вкладке «Сервер»; компьютер: рядом с полем ввода). Одна просьба —
«выставь оценки 9А, скинь детям домашку, подготовь сценарий на выпускной, сообщи родителям итоги» — превращается в план,
и несколько агентов работают **параллельно**: на сервере (WhatsApp, почта, документы, тексты) и на компьютере (браузер, BilimClass, приложения).
Части, которым нужен результат других, ждут их. Живая карточка показывает статус каждого агента; в конце — общий отчёт и уведомление.
Лимит одновременных агентов команды: `STELLA_TEAM_MAX` (по умолчанию 4).

**Голос:** кнопка 🎤 в приложении на телефоне — русский, казахский, английский (кнопка RU/KZ/EN). На компьютере — голосовой режим Stella.

**WhatsApp для учителя:** `create_group` (создать группу класса/родителей) и `broadcast` (одно сообщение нескольким контактам, не больше 30, с паузами 2–5 с — чтобы не заблокировали номер).

## Знакомство и сервисы

- **Знакомство:** сразу после регистрации (телефон и Stella.exe) — анкета «Расскажите о себе». Профиль общий для телефона, ПК и сервера, агент учитывает его везде. Изменить: телефон → «Ещё» → «Обо мне» или Stella → «Облако» → «Обо мне».
- **Вкладка «Сервисы»** в приложении:
  - **BilimClass** — логин/пароль хранятся на сервере зашифрованными (AES-256-GCM). Агент открывает сайт в браузере агента на ПК и вызывает `service_login` — Stella сама вписывает логин и пароль, **агент их не видит**.
  - **Почта** (Gmail, Яндекс, Mail.ru, Outlook, iCloud; нужен «пароль приложения») — агент читает, ищет и отправляет письма по просьбе. Пароль используется только сервером.
  - **Офис** — `create_presentation` / `create_document`: готовый .pptx / .docx (проектная работа с титульным листом, оглавлением, ГОСТ-оформлением) за доли секунды, сразу открывается.
  - **Уведомления** — `notify_user`: агент присылает пуш на телефон и ПК.
- **Расширение «Стелла — AI Browser Agent»** встроено в Stella.exe и загружается в браузер агента (кнопка «🧩 Расширение Stella»).

## Если на компьютере пропал свет

Пока на ПК идёт задача, Stella раз в 3 минуты отправляет на сервер снимок папки проекта (без `node_modules`, `dist` и т. п., до 300 МБ).
Сервер каждые 15 секунд проверяет, жив ли ПК. Если ПК пропал посреди задачи и не вернулся за 45 секунд — сервер распаковывает снимок
в контейнер этого аккаунта и **доделывает задачу сам**, с полной историей. На телефон приходит уведомление «⚡ задача продолжена на сервере».
Когда ПК включится, Stella покажет это в чате и кнопку **«⬇ Забрать файлы с сервера»** — результат скачается в отдельную папку
`<проект>-с-сервера-<дата>`, ваши файлы не перезаписываются.

Чтобы снимки работали, выберите в Stella слева **папку проекта** (а не весь профиль).

## Защита (что включено и как усилить)

Включено всегда:
- пароли: scrypt + соль, минимум 10 символов, проверка простых паролей; **блокировка аккаунта** после 5 неверных попыток (15 мин, дальше дольше);
- **двухфакторная защита** (Google Authenticator / Aegis / 1Password): телефон → «Ещё» → «Безопасность»;
- сессии хранятся только как хеши, истекают через 30 дней бездействия, список устройств и «Выйти на всех устройствах», уведомление о каждом новом входе;
- лимиты запросов по IP (nginx + сервер), подделка X-Forwarded-For не помогает; журнал входов: `/var/lib/stella/security.log`;
- заголовки безопасности (CSP, HSTS, запрет фреймов), версия nginx скрыта;
- контейнеры агентов в отдельной сети: не видят сервер, соседей, внутренние адреса и метаданные Hetzner.

Капча Cloudflare Turnstile (бесплатно): dash.cloudflare.com → Turnstile → Add widget → домен `stellalive.duckdns.org` → получите Site Key и Secret Key, затем:
```bash
curl -fsSL https://raw.githubusercontent.com/a1x10/project3/claude/happy-ritchie-vx32ws/stella-cloud/install.sh | sudo DUCKDNS=stellalive TURNSTILE=1 bash
```

Защита самого сервера (файрвол, fail2ban, SSH, автообновления) — интерактивно, с вопросами:
```bash
curl -fsSL https://raw.githubusercontent.com/a1x10/project3/claude/happy-ritchie-vx32ws/stella-cloud/scripts/harden.sh | sudo bash
```

Спрятать сервер и защититься от DDoS — Cloudflare Tunnel (нужен свой домен в Cloudflare; DuckDNS по своей природе показывает IP):
Cloudflare → Zero Trust → Networks → Tunnels → Create → скопируйте токен →
```bash
curl -fsSL https://raw.githubusercontent.com/a1x10/project3/claude/happy-ritchie-vx32ws/stella-cloud/install.sh | sudo TUNNEL=stella.вашдомен.com bash
```
затем в туннеле Public Hostname: `stella.вашдомен.com` → `http://localhost:<порт Stella>`. Stella перестаёт быть доступной по IP вообще.

## Безопасность

- **Каждый аккаунт работает в своём Docker-контейнере** (`stella-<имя>`): не root, без Linux-привилегий (`--cap-drop ALL`, `no-new-privileges`), лимиты памяти/CPU/процессов, примонтирована только его домашняя папка. Docker-сокет, настройки сервера и код Stella внутри не видны — агент не может «попросить систему» что-то сделать.
- Если Docker недоступен — запасной режим: отдельный Linux-пользователь + лимиты systemd.
- Сама служба работает от root (создаёт пользователей и контейнеры).
- HTTPS (Let's Encrypt) + HSTS: браузер открывает сайт только по HTTPS — это и защищает от перехвата.
- На сервере агент по умолчанию работает в режиме «Полный автомат» (подтверждать действия некому) — внутри своего пользователя. Режим меняется в «Ещё».
- Переписки WhatsApp хранятся только на вашем сервере: `/var/lib/stella/users/<имя>/whatsapp/`.
