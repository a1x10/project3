# Подключение телефона к телевизору одной кнопкой

Скрипт сам: жмёт «Домой» → опускает шторку → жмёт «Трансляция» → выбирает телевизор → подтверждает.

## Подготовка (один раз)

1. **ADB**: скачай [platform-tools](https://developer.android.com/tools/releases/platform-tools), распакуй, например, в `C:\platform-tools` и добавь эту папку в PATH (или запускай с `--adb C:\platform-tools\adb.exe`).
2. **Python 3** с python.org (галочка «Add to PATH»).
3. На телефоне (Xiaomi / Redmi / POCO):
   - Настройки → О телефоне → 7 раз нажать на «Версия MIUI/HyperOS» → режим разработчика включён.
   - Настройки → Расширенные настройки → Для разработчиков:
     - **Отладка по USB** — вкл.
     - **Отладка по USB (настройки безопасности)** — вкл. ⚠️ без этого Xiaomi не даёт нажимать на экран через ADB.
4. Подключи телефон кабелем и нажми «Разрешить» в окне на телефоне. Проверка: `adb devices`.

## Запуск

Двойной клик по `cast_to_tv.bat` (внутри впиши имя своего ТВ), или:

```bash
python cast_to_tv.py --tv "Xiaomi TV"
```

## Без кабеля (по Wi-Fi)

Один раз по кабелю: `adb tcpip 5555`, потом:

```bash
adb connect 192.168.1.50:5555
```

```bash
python cast_to_tv.py --tv "Xiaomi TV" --serial 192.168.1.50:5555
```

(IP телефона: Настройки → О телефоне → Общая информация → IP-адрес.)

## Если не работает

- Скрипт пишет, какие надписи видит на экране — подставь точное имя ТВ в `--tv`.
- Если плитка называется по-другому — добавь название в список `CAST_TILE_NAMES` в `cast_to_tv.py`.
