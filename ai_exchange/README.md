# AI Exchange — симулятор криптобиржи с ИИ-трейдером

Демонстрационный стенд для большого экрана: на локальной бирже BTC/USDT торгуют ~50 ботов, а среди них —
ИИ-маркет-мейкер (Avellaneda–Stoikov + прогноз LightGBM + риск-менеджмент). Всё работает **локально, без интернета и
без видеокарты** (нужен только Python 3.12). Сайт — тёмная тема, крупные шрифты, русский язык.

## Быстрый старт (Windows PowerShell)

```powershell
# 1. Перейдите в папку проекта
cd путь\к\ai_exchange

# 2. Создайте виртуальное окружение и установите зависимости (один раз)
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt

# 3. Обучите модель ИИ (один раз, ~3–8 минут на ноутбуке без видеокарты)
python train.py

# 4. Запустите всё — браузер откроется сам на http://localhost:8000
python run.py
```

Если PowerShell ругается на запуск `Activate.ps1`, выполните один раз в этом окне:
`Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` и повторите шаг активации.
Без активации окружения можно вызывать напрямую: `.\.venv\Scripts\python.exe run.py`.

Остановить сервер: `Ctrl+C` в окне PowerShell. Другой порт: `python run.py --port 8080`.
Если модель не обучена, `run.py` сам запустит быстрое обучение (1–2 минуты).

### Сценарий демонстрации (3–5 минут)
1. Запустите `python run.py`, дайте поработать 1–2 минуты на **x1** — покажите книгу ордеров, стрелки сделок ИИ, «мысли».
2. Включите **x10** — график побежит, кривая прибыли ИИ растёт, Buy&Hold колеблется вместе с рынком.
3. Нажмите **«⚡ Рыночный шок»**. Крупный игрок сбрасывает ~20 BTC, цена резко падает на 2–5 %.
   ИИ показывает «Аварийный режим», закрывает позицию, спред расширяется; потом он осторожно возвращается
   («Восстановление»). Buy&Hold в это время теряет несколько процентов.

## ИИ-аналитик (необязательно)

Скопируйте `.env.example` в `.env` и впишите `ANTHROPIC_API_KEY=...`. Раз в 60 секунд статистика уходит в Claude API,
а короткий комментарий на русском появляется в правой панели. Нет ключа, нет интернета или ошибка API — блок
скрыт, остальное работает как обычно (по умолчанию используется `claude-haiku-5-5`, можно сменить через `ANTHROPIC_MODEL`).

### REST API биржи
| Метод | Путь | Описание |
|---|---|---|
| POST | `/order` | `{"participant":"user","side":"buy","type":"limit","price":65000,"qty":0.01}` (type: `limit`/`market`, опц. `post_only`) |
| DELETE | `/order/{id}` | снять заявку (`?participant=user`) |
| GET | `/orderbook?depth=20` | стакан: `[цена, объём, число заявок]` |
| GET | `/balance/{id}` | кошелёк участника (`ai`, `user`, `whale`, `noise_3` …) |
| GET | `/trades?limit=50` | последние сделки |

Через REST торгует демо-участник `user` (10 000 USDT и 0.1 BTC). Посмотреть сводку: `http://localhost:8000/api/summary`,
интерактивная документация API: `http://localhost:8000/docs`.

### Как работает ИИ
* **Avellaneda–Stoikov**: резервная цена = середина − `γ·σ²·τ·(позиция − цель)`; спред = `γσ²τ + (2/γ)·ln(1+γ/k)`,
  но не уже 15 б.п. (при комиссии 0.05 % с каждой стороны меньше не имеет смысла). Две котировки на сторону.
* **LightGBM** каждые 100 мс (0.03 мс на прогноз) предсказывает изменение средней цены за ближайшие 3 с по 19 признакам:
  дисбаланс книги (1/5/10 уровней), микроцена, спред, поток сделок (1/3/10 с), доходности (1/3/10/30 с), волатильность
  (10/60 с), интенсивность сделок, глубина, текущая позиция. Прогноз сдвигает котировки и расширяет спред, а при сильном
  прогнозе против стороны — уменьшает объём этой стороны.
* **Риск**: лимит позиции 0.5 BTC (при капитале 10 000 USDT фактически ограничивает баланс); спред растёт вместе с
  волатильностью; при падении > 0.55 % за 10 с или > 0.35 % за 3 с — снять заявки и **аварийно закрыть позицию**,
  затем 8+ секунд пауза и постепенное возвращение с широким спредом.
* Старт: баланс 10 000 USDT; ИИ изучает рынок 30 с, покупает стартовую позицию (35 % капитала в BTC), затем котирует.
* Buy&Hold: на те же 10 000 USDT в момент старта ИИ покупается BTC по лучшему аску с комиссией и удерживается.

### Честность (ИИ не подглядывает)
* ИИ общается с биржей только через `Gateway`: публичный стакан, лента сделок, **свои** заявки и кошелёк.
  У него нет доступа к будущим ценам, к ботам и к скрытой «справедливой цене» симуляции.
* Признаки считаются без собственных заявок и сделок ИИ, метки в обучении — будущее изменение цены — используются
  только как цель; проверка модели идёт на отдельных симуляциях.
* Автотесты `tests/test_api_sim.py` проверяют: (1) если «изменить будущее» мира после момента T, всё, что произошло до T
  (сделки рынка и ИИ), остаётся побитово тем же; (2) в коде ИИ нет обращений к внутренностям симуляции.
* Прибыль ИИ — только спред и прогноз; комиссия 0.05 % платится со всех сделок, включая ИИ.
* **Оговорка**: это симулятор. «Ценовые» боты видят справедливую цену с задержкой и шумом (так моделируется
  информированный поток), и ИИ учится замечать его след в стакане/ленте. Это даёт ML-модели реальный, но синтетический
  сигнал. Цифры прибыли описывают поведение ИИ в этом искусственном мире, а не на реальной бирже.

## Кнопка «🌀 Полная мощность» (охлаждение, только Windows)

Кнопка в шапке включает в Windows **активную политику охлаждения системы** (`powercfg … SYSCOOLPOL`): вентилятор
раскручивается раньше, чем процессор начнёт сбрасывать частоту. Повторное нажатие возвращает прежнюю настройку
(исходные значения запоминаются в `logs/cooling_prev.json`). Работает только при открытии сайта с того же компьютера.
Ровно 100% оборотов вентилятора Windows и программы выставить не могут: на **ASUS VivoBook** дополнительно откройте
приложение **MyASUS → Режим вентилятора → «Производительность»** или нажмите **Fn+F** (на многих моделях). Если `powercfg`
пишет «отказано в доступе», запустите PowerShell от имени администратора. На Linux/macOS кнопка просто сообщит, что
недоступна.

## Прозрачность ML-модели («Внутри модели»)

Для показа инвесторам каждое решение ИИ можно проверить: что модель видела, что предсказала, куда поставила заявки и
что случилось на самом деле. Торговую логику и параметры ИИ эти функции **не меняют**, они только наблюдают
(тест `test_logging_does_not_change_trading` сравнивает сделки с журналом и без него).

**На сайте** справа в панели ИИ две кнопки (горячая клавиша `M` открывает/закрывает панель, `Esc` закрывает):
* **🔍 Внутри модели**: 19 признаков в реальном времени; текущий прогноз и то, как он сдвинул котировки (прогноз →
  сдвиг, поправка за позицию, итоговый центр, ширина спреда, заявки bid/ask); график «прогноз vs факт» за последние
  10 минут; точность направления за сессию (обновляется вживую, плюс последние 100 прогнозов, корреляция, ошибка MAE
  против «прогноза нуль»); важность признаков горизонтальными барами.
* **⬇ Скачать лог**: выгружает `predictions.csv` текущей сессии (кнопка есть и внутри панели).

**Журнал `logs/predictions.csv`** (создаётся при каждом запуске `run.py`; журнал предыдущей сессии переименовывается в
`predictions_<дата>_<время>.csv`). Одна строка — один шаг ИИ (10 раз в секунду симулированного времени). Строка
записывается только через `horizon_s` секунд (3 с), когда уже известен факт, поэтому последние 3 секунды сессии в файл
не попадают. Кодировка UTF-8 (с BOM, чтобы открывалось в Excel), разделитель — запятая.

| Столбцы | Смысл |
|---|---|
| `time_utc`, `sim_time_s`, `mode`, `mid` | время, время симуляции, режим ИИ (`quoting`, `caution`, `emergency`, `recovery`), средняя цена |
| `imb1`, `imb5`, `imb10` | дисбаланс стакана на 1/5/10 уровнях (−1…+1, плюс = перевес покупателей) |
| `micro_bps`, `spread_bps`, `depth_log` | микроцена − середина, спред рынка (б.п.), глубина стакана |
| `flow_1s`, `flow_3s`, `flow_10s`, `signed_vol_3s`, `trade_rate_3s` | поток сделок: перевес покупок над продажами, чистый объём (BTC), число сделок |
| `ret_1s`, `ret_3s`, `ret_10s`, `ret_30s` | изменение цены (б.п.) |
| `vol_10s`, `vol_60s`, `vol_ratio` | волатильность (б.п. за √с) и их отношение |
| `pos_norm`, `position_btc` | позиция ИИ: доля от лимита 0.5 BTC и в BTC |
| `pred_model_bps` | прогноз модели (сырой): ожидаемое изменение цены за `horizon_s` секунд |
| `pred_used_bps`, `shift_bps` | сглаженный прогноз, который использует ИИ, и сдвиг котировок из-за него |
| `skew_bps`, `half_bps`, `ai_spread_bps` | поправка за позицию (Avellaneda–Stoikov), полуспред и полный спред ИИ |
| `bid`, `ask`, `bid_offset_bps`, `ask_offset_bps` | реальные лучшие заявки ИИ и их смещение от середины (пусто, если заявки сняты) |
| `horizon_s`, `mid_after`, `actual_move_bps` | горизонт, цена через горизонт и фактическое движение (б.п.) |
| `direction_hit` | 1 — направление угадано, 0 — нет, пусто — прогноз нейтральный (< 0.5 б.п.) или цена не изменилась |

Оценка точности направления считается по **сырому** прогнозу модели (`pred_model_bps`). Признаки в журнале
вычисляются без собственных заявок и сделок ИИ, как и при торговле.

## Обучение и метрики

`python train.py` (или `python train.py --quick` на ~1 минуту):
запускает 100 симуляций по 30 минут (параллельно на всех ядрах, случайные шоки и «киты»), в каждой торгует базовый ИИ;
записывает признаки и метку «изменение цены через 3 с», обучает LightGBM, проверяет на отдельных симуляциях и сохраняет
`models/model.txt` + `models/meta.json`. Параметры: `--episodes`, `--minutes`, `--workers`, `--rounds`, `--model-dir`, `--logs-dir`.

В конце обучения пишется отчёт **`logs/train_report.json`** (для машин) и **`logs/train_report.txt`** (для людей):
размер выборки, метрики на проверке (корреляция, точность направления, MAE, RMSE, R²), важность признаков, параметры
LightGBM, время обучения и версии библиотек.

## Результаты (на тестовой машине, симулированное время)

Все цифры — в **симулированном** времени, на сидах, не использовавшихся при подборе параметров; ИИ — режим «ML» (LightGBM),
для сравнения — базовый режим (только Avellaneda–Stoikov). Комиссия 0.05 % учтена. Стартовый баланс 10 000 USDT.

| Сценарий (10 запусков) | ИИ (ML), среднее | Buy&Hold | Преимущество над B&H | ИИ впереди B&H | Базовый режим (без ML) |
|---|---|---|---|---|---|
| 30 мин, без шока | +3.93 % (мин +2.63 %) | +1.16 % | +2.77 % | 10 из 10 | +2.62 %, преимущество +1.46 % |
| 30 мин, шок на 15-й минуте | +2.90 % (мин +2.04 %) | −0.37 % | +3.27 % | 10 из 10 | +1.90 %, преимущество +2.27 % |
| 5 мин, без шока | +0.55 % (мин +0.15 %) | −0.14 % | +0.69 % | 9 из 10 | +0.30 %, преимущество +0.43 % |
| 5 мин, шок на 2.5-й минуте | +0.20 % | −1.63 % | +1.83 % | 10 из 10 | −0.18 %, преимущество +1.46 % |

Живой прогон (`run.py` + `live_check.py`: 5 реальных минут на x10 ≈ 51 минута симуляции, шок посередине): ИИ **+5.40 %**
против Buy&Hold **+2.39 %**, 4128 сделок, 78 % прибыльных, максимальная просадка 0.40 %, цена после шока упала на 3.9 %, ИИ закрыл
позицию (0.046 → 0 BTC) и расширил спред до 140 б.п., ошибок сервера нет, ≈10 кадров в секунду.

Качество прогноза LightGBM на отдельных симуляциях (3 с вперёд): корреляция ≈ 0.4, направление угадано в ≈ 60 % случаев
(≈ 73 % среди 20 % самых уверенных прогнозов); ML добавляет к базовой логике около +1 % за 30 минут.

Как читать цифры: ИИ держит ~35 % капитала в BTC, поэтому на росте рынка Buy&Hold может его обогнать, а на 5-минутных
отрезках без шока результат сильно зависит от случайного движения цены (в одном запуске из десяти ИИ уступил).
Основной доход ИИ даёт спред при потоке «шумовых» сделок — это свойство симулятора (много неинформированного потока),
на реальной бирже он был бы значительно скромнее.

## Частые проблемы
* **Порт 8000 занят** — `python run.py --port 8080`.
* **Модель «обучена на другом наборе признаков»** — перезапустите `python train.py`.
* **Пустой экран / «Нет связи»** — проверьте, что окно PowerShell с `run.py` не закрыто; обновите страницу (F5).
* **Медленно** — симуляция лёгкая (тысячи шагов в секунду), x10 нагружает процессор на единицы процентов; обычно причина в
  энергосбережении ноутбука — включите режим «Высокая производительность».
