# Яндекс Станция через Home Assistant

Яндекс не даёт локального API, поэтому колонкой управляет Home Assistant (HA) с интеграцией [YandexStation](https://github.com/AlexxIT/YandexStation). HomeGuard говорит только с REST API самого HA.

## 1. Поставить Home Assistant

На той же Raspberry Pi или на любой машине в сети (нужен Docker):

```bash
cd homeguard
docker compose -f docker-compose.ha.yml up -d
```

Откроется `http://<ip-машины>:8123`. Создай пользователя при первом входе.

## 2. Поставить интеграцию YandexStation

1. Установи [HACS](https://hacs.xyz/docs/use/download/download/) (в Docker-варианте — через терминал контейнера, см. инструкцию HACS).
2. HACS → Интеграции → найди **Yandex Station** → скачать → перезагрузить HA.
3. Настройки → Устройства и службы → Добавить интеграцию → **Yandex Station** и войди в аккаунт Яндекса. Пароль вводится только в HA.
4. Станция появится как `media_player.yandex_station_…`.

## 3. Токен для HomeGuard

В HA: профиль (левый нижний угол) → **Безопасность** → **Долгоживущие токены** → создать. Скопируй токен (покажут один раз).

## 4. Подключить

Панель HomeGuard → **Колонки** → адрес `http://<ip-HA>:8123` и токен. Токен хранится в `data/homeguard.db` открытым текстом и наружу не отдаётся.

Что умеет вкладка: плей/пауза/следующий/предыдущий, громкость, mute, а также:

- **Команда** — как будто сказал Алисе вслух («включи свет на кухне», «какая погода»). Это работает и для умного дома, подключённого к Яндексу.
- **Произнести** — колонка просто зачитает текст.

Показываются все `media_player` из HA, колонки Яндекса — первыми. Адрес HA принимается только из локальной сети.
