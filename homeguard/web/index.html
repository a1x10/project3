История проверок

Движки

Файлы .conf (WireGuard / AmneziaWG) или .ovpn (OpenVPN) берутся в личном кабинете VPN-сервиса. Команды запуска скриптов из файлов вырезаются при импорте.

Как включить управление на Sony Bravia
  1. Настройки → Сеть → Домашняя сеть → Управление по IP
  2. Аутентификация: Обычная и Pre-Shared Key
  3. Задай Pre-Shared Key (его вводишь здесь)
  4. Для включения из ожидания: Удалённый запуск = Вкл
Где взять IP и токен
  1. IP: вкладка «Устройства», закрепи его за стиралкой в роутере.
  2. Токен (32 символа) — из аккаунта Xiaomi. Проще всего утилитой Xiaomi-cloud-tokens-extractor (запускается у тебя на компьютере, пароль никому не передаётся).
  3. Модель определится сама; описание управления скачается с miot-spec.org.

Работает с устройствами, у которых включено локальное управление (протокол miIO/MIoT). Часть новых устройств Xiaomi работает только через облако — к ним не подключиться.

Подключение Home Assistant

Яндекс Станция управляется через Home Assistant с интеграцией YandexStation. Пошаговая инструкция: docs/home-assistant.md в репозитории.
