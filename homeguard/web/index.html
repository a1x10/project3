Уровень защиты

Файлы .conf (WireGuard) или .ovpn (OpenVPN) берутся в личном кабинете VPN-сервиса. Команды запуска скриптов из файлов вырезаются при импорте.

Как включить управление на Sony Bravia
  1. Настройки → Сеть → Домашняя сеть → Управление по IP
  2. Аутентификация: Обычная и Pre-Shared Key
  3. Задай Pre-Shared Key (его вводишь здесь)
  4. Для включения из ожидания: Удалённый запуск = Вкл
