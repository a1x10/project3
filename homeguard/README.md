# HomeGuard

Домашний шлюз-фильтр: список устройств в сети, журнал сайтов, блокировка рекламы/трекеров/вирусов/фишинга по DNS, три уровня защиты и страница «Стоп!» с анимацией.

Это **этап 1 (MVP)**. Дальше по плану: VPN (WireGuard, «Планета»), Bravia, Xiaomi, Яндекс Станция, Android-приложение.

## Установка на Raspberry Pi / сервер (автозапуск)

```bash
git clone https://github.com/a1x10/project3 && cd project3/homeguard
sudo ./deploy/install.sh
```

Скрипт ставит пакеты (WireGuard, OpenVPN, ClamAV), кладёт сервис в `/opt/homeguard`, создаёт `/etc/homeguard.env` и включает службы systemd: `homeguard` (поднимается после перезагрузки, перезапускается при падении) и таймер ежедневного обновления баз. Логи: `journalctl -u homeguard -f`.

## Запуск для разработки

```bash
cd homeguard
pip install -r requirements.txt
HG_DEMO=1 python -m homeguard      # демо с выдуманными устройствами
python -m homeguard                # боевой режим: скан реальной сети
```

Панель: http://localhost:8080

## Как включить фильтр на реальной сети (Raspberry Pi / ПК в LAN)

1. Дай машине статический IP (пусть `192.168.3.2`).
2. `HG_DNS_PORT=53 HG_BLOCK_IP=192.168.3.2 HG_WEB_PORT=80 sudo -E python -m homeguard`
3. В роутере укажи DNS-сервер, выдаваемый по DHCP, = `192.168.3.2` (или вручную на устройстве).
4. Заблокированный домен резолвится в `HG_BLOCK_IP`, а на порту 80 открывается страница блокировки.

Через DNS видны только **домены**, не содержимое страниц (HTTPS). Устройство с включённым DoH в браузере может обойти фильтр — «Строгая» защита блокирует известные DoH-серверы.
Страница блокировки работает для HTTP; для HTTPS-сайтов браузер покажет ошибку сертификата — это нормально, сайт всё равно не загрузится.

## Уровни защиты

| Уровень | Что блокирует |
|---|---|
| Выключена | ничего, только журнал |
| Обычная | реклама |
| Средняя | реклама, трекеры, вирусы, фишинг |
| Строгая | + 18+, подозрительные зоны (.zip, .top…), DoH |

Полные списки: `python scripts/update_blocklists.py` (кладёт в `data/blocklists/*.remote.txt`). Свои домены — в `data/blocklists/<категория>.txt`.
Для проверки есть тестовые домены `blocked-malware.test`, `blocked-phishing.test`.

## VPN (Планета и любой другой сервис)

Вкладка **VPN**: добавляешь серверы файлами `.conf` (WireGuard) или `.ovpn` (OpenVPN, логин/пароль — в форме), выбираешь страну, жмёшь «Подключить». Переключение сервера = нажать «Подключить» на другой карточке. Страна определяется по названию (или выбери вручную).

- Подключение для **всей сети**: машина становится шлюзом (ip_forward + NAT через туннель `hgvpn`). Устройства должны ходить через неё: она — шлюз по умолчанию (или в роутере прописан маршрут/DHCP-шлюз).
- **Kill switch**: пока туннель не поднят, транзит из LAN режется.
- Нужны `wireguard-tools` / `openvpn`, `iptables` и запуск от root: `sudo apt install wireguard-tools openvpn iptables`.
- Безопасность: из импортируемых конфигов вырезаются `PostUp/PreUp/…`, `up/down/script-security/plugin` и т. п. (иначе чужой конфиг выполнил бы команды от root). Ключи нигде не отдаются через API, файлы хранятся с правами 600 в `data/vpn/`.
- Без root/wg: `HG_VPN_DRYRUN=1` — команды только запоминаются (демо-режим включает это сам).
- Поддерживаются только WireGuard и OpenVPN. Если Планета выдаёт ссылки `vless://` / подписку — это отдельный этап (нужен xray/sing-box).

## Sony Bravia

Вкладка **Телевизоры**: питание, громкость, mute, вход (HDMI…), запуск приложений (YouTube, Netflix…), пульт (стрелки, OK, назад, домой).

На телевизоре: Настройки → Сеть → Домашняя сеть → **Управление по IP** → аутентификация «Обычная и Pre-Shared Key», задай Pre-Shared Key; для включения из ожидания включи **Удалённый запуск**. Название пунктов зависит от модели.
Потом в панели «Добавить телевизор»: имя, IP (виден на вкладке «Устройства»), ключ. Лучше закрепить за телевизором постоянный IP в роутере.

- Ключ хранится в `data/homeguard.db` открытым текстом (файл вне git) и наружу через API не отдаётся. Панель доступна только после входа через Telegram.
- Панель принимает только локальные IP телевизоров (192.168.x.x, 10.x…), чтобы её нельзя было использовать для запросов в интернет.
- Если телевизор «не отвечает» в глубоком сне — включи сетевой режим ожидания.

## Умный дом: Xiaomi (стиральная машина и другие)

Вкладка **Умный дом**. Работает по локальному протоколу miIO/MIoT, без облака Xiaomi. Панель сама скачивает описание модели с miot-spec.org (один раз, кэш в `data/miot/`) и строит по нему интерфейс: статус, программа, температура, отжим, блокировка от детей, кнопки Старт/Пауза и т. д. Подписи для частых параметров переведены на русский.

Что нужно: IP стиралки (закрепи в роутере) и **токен** (32 символа) из аккаунта Xiaomi. Токен достаёт утилита [Xiaomi-cloud-tokens-extractor](https://github.com/PiotrMachowski/Xiaomi-cloud-tokens-extractor), которую запускаешь у себя.

- «Старт» требует подтверждения в панели. Менять можно только то, что разрешено описанием модели и допустимо по значениям.
- Токен лежит в `data/homeguard.db` открытым текстом и наружу не отдаётся. Панель доступна только после входа через Telegram.
- Не все устройства Xiaomi доступны локально: часть новых моделей работает только через облако. Тогда добавление вернёт «Устройство не отвечает».
- Для тестов есть имитация: `python tests/fake_miio.py`.

## Яндекс Станция (через Home Assistant)

Вкладка **Колонки**: пауза/плей, треки, громкость, mute и поле «Скажи Алисе» (команда или озвучка текста). Подробная установка Home Assistant, интеграции YandexStation и токена: [docs/home-assistant.md](docs/home-assistant.md); контейнер HA: `docker compose -f docker-compose.ha.yml up -d`.

## Вход через Telegram

При первом открытии панели — 3D-знакомство и подключение своего бота: создай его у [@BotFather](https://t.me/BotFather) (`/newbot`) и вставь токен. Затем «Войти через Telegram» → бот → Start. **Первый вошедший — владелец.** Остальных владелец пропускает кнопкой в боте; управлять ими можно в «Настройках».

Бот также присылает тревоги (заблокирован вирус/фишинг) и понимает `/status`, `/level`, `/vpn`, `/check <ссылка>`.

## Антивирус

Вкладка «Антивирус»: проверка ссылок и файлов. Работает сразу (базы + эвристики: подделки банков и Госуслуг, punycode, двойные расширения `.pdf.exe`), а точнее — с бесплатными ключами:
- Google Safe Browsing — [ключ](https://developers.google.com/safe-browsing/v4/get-started); с ним HomeGuard ещё и сам проверяет все новые сайты из DNS-журнала и блокирует опасные;
- VirusTotal — [ключ](https://www.virustotal.com/gui/my-apikey) (файлы проверяются по хэшу, сам файл не отправляется);
- ClamAV — ставится install.sh, проверяет файлы локально.

## Настройки (переменные окружения)

`HG_DNS_PORT` (5353), `HG_UPSTREAM` (1.1.1.1), `HG_WEB_PORT` (8080), `HG_BLOCK_IP` (127.0.0.1), `HG_SCAN_INTERVAL` (30 с), `HG_LAN_IFACE`, `HG_TG_TOKEN`, `HG_GSB_KEY`, `HG_VT_KEY`, `HG_AUTH` (0 — без входа, только для разработки), `HG_VPN_DRYRUN`, `HG_DB`, `HG_DEMO`.
