# STELLS — AI Platform

Настольное приложение (Windows / macOS / Linux) проекта **STELLS**, разработанного Алексеем (@l3xn0).
Даёт доступ к моделям LLM / LM / машинное зрение / VLM / SLM / LMM, управляет одноплатными
компьютерами и микроконтроллерами, запускает машинное зрение на компьютере и на плате,
содержит пульты для дронов, машин, роботов, камер и Wake-on-LAN.

## Что умеет

| Функция | Как работает |
|---|---|
| Заставка 3D + приветствие | При каждом запуске: «Добрый вечер, {имя}» (голосом), загрузка 5 секунд |
| Автозапуск с компьютером | Windows/macOS — Login Items, Linux — `~/.config/autostart/stells.desktop` |
| Регистрация | Имя + номер телефона, хранится локально |
| Выбор платы | 180+ плат: Raspberry Pi, Banana Pi, ODROID, Arduino, NanoPi, Jetson, Orange Pi, Radxa, ESP32… Поиск и фильтры, «No filtering» |
| Выбор ОС | 150+ ОС (Raspberry Pi OS, Ubuntu, Debian, Armbian, OpenWrt, Windows IoT, RTOS…) с фильтром под тип платы |
| Модели + SLT-ключ | Без действительного ключа программа не запускается. Ключи выпускает разработчик: `npm run keygen` |
| Прошивка платы | Кнопка «Скачать» собирает архив: агент для Linux-плат или скетч для Arduino/ESP32 + конфиг + инструкция |
| Машинное зрение | Встроенное (детектор движения, трекинг цели по цвету) + Python-модуль с OpenCV и моделями ONNX/YOLO. Запускается автоматически при старте |
| Связь с платой | Wi-Fi/Ethernet (WebSocket), автопоиск в сети (UDP), USB/Serial, свой коннектор, симулятор |
| Пульт дрона | Стики, клавиатура, геймпад, ARM/взлёт/посадка/RTL, 3D-модель ориентации, телеметрия, видео, AI-пилот (бета) |
| Свой коннектор | Окно как VS Code: редактор + настоящий терминал. Скрипт на 16 языках, кнопка «Подключить коннектор» |
| Машины, роботы, камеры, WOL | Отдельные пульты: моторы, сервоприводы, запись видео/снимки/уведомления, магический пакет WOL |

## Запуск из исходников

```bash
cd stells
npm install
npm start
```

## Сборка установщиков

```bash
npm run dist:win     # .exe (NSIS-установщик + portable)
npm run dist:mac     # .dmg
npm run dist:linux   # AppImage + .deb
```

Готовые файлы появляются в `stells/dist/`. Также сборку для всех трёх ОС делает GitHub Actions
(`.github/workflows/stells-build.yml`) — запустите вручную во вкладке Actions или создайте тег `stells-v1.0.0`.

## SLT-ключи (для разработчика)

```bash
npm run keygen            # один ключ
npm run keygen -- 20      # 20 ключей
node tools/keygen.js check SLT-XXXX-XXXX-XXXX-XXXX
```

**Перед выпуском задайте свой секрет:** создайте файл `stells/key-secret.json` со строкой, например
`"мой-длинный-секрет"`. Его читают и приложение, и генератор ключей; в git файл не попадает.
В GitHub Actions добавьте секрет репозитория `STELLS_KEY_SECRET` — сборка сама создаст этот файл.
Без файла используется тестовый секрет `stells-l3xn0-change-me`.
Проверка ключа офлайновая, поэтому секрет находится внутри приложения — это защита от случайных
пользователей, но не от взлома. Для серьёзной защиты нужна проверка ключа на вашем сервере.

## Подключение своих моделей

1. Заполните `url` в `models.json` (GitHub Releases, свой сервер, Hugging Face) — приложение скачает модель.
2. Или в приложении: «Модели» → «Подключить файл модели».
3. Файлы `.onnx` (YOLOv5/v8) + `.txt` со списком классов автоматически подхватываются машинным зрением на ПК и на плате.

Своё хранилище прошивок: в «Настройках» укажите адрес, приложение будет брать `{адрес}/firmware/{id-платы}.zip`,
а если хранилище недоступно — соберёт прошивку само.

## Структура

```
stells/
  main.js              главный процесс: окно, автозапуск, ключи, загрузки, сеть, терминал, коннекторы
  preload.js           безопасный мост к интерфейсу
  renderer/            интерфейс (3D на Three.js, мастер настройки, панель, пульты, IDE)
  firmware/agent/      STELLS Agent для платы (Python): WebSocket, видео MJPEG, ONNX, GPIO, MAVLink, WOL
  firmware/arduino/    прошивка для Arduino/ESP32 (USB-Serial, JSON-команды)
  firmware/connectors/ примеры коннекторов (Python, JavaScript)
  vision/              локальный модуль машинного зрения для компьютера (Python + OpenCV)
  models.json          каталог моделей
  tools/keygen.js      генератор SLT-ключей
```

## Протокол управления (общий для платы, USB и коннекторов)

JSON-строки. От приложения:

```json
{"type":"hello","token":""}
{"type":"drive","x":0.2,"y":0.6}
{"type":"servo","index":0,"angle":30}
{"type":"rc","roll":0,"pitch":0.3,"yaw":0,"throttle":0.55}
{"type":"drone","cmd":"arm|disarm|takeoff|land|rtl|mode","value":3}
{"type":"wol","mac":"AA:BB:CC:DD:EE:FF"}
```

От платы: `{"type":"telemetry","system":{...},"drone":{...},"vision":{...}}`.
