# Stella

Десктоп-приложение в стиле Claude Code / Codex / Antigravity поверх **Antigravity CLI (`agy`)**.

## Что делает
1. При запуске **всегда перезапускается от имени администратора** (UAC).
2. Проверяет, установлен ли Antigravity CLI. Если нет — экран «Установка системных файлов…» и автоустановка
   (`irm https://antigravity.google/cli/install.ps1 | iex`, запасной вариант — `install.cmd`).
3. Запускает **скрытый терминал** с `agy` внутри приложения (отдельного окна консоли нет).
4. Кнопка **«Войдите в систему»** → вход через Google → открывается интерфейс чата.
5. Каждый запрос уходит в `agy -p "<запрос>" --output-format stream-json`, а ответ (текст, вызовы инструментов, ошибки) стримится в чат. Диалог продолжается через `--conversation <id>` / `-c`.
6. **Чёрная кнопка** (как на скриншоте) → `/voice live`: агент слушает и отвечает голосом, пока режим включён. Повторное нажатие / «Завершить» / Esc — выключить (F6).
7. Любая команда, начинающаяся с `/` (например `/logout`, `/help`), уходит прямо в терминал agy.

## Готовый Stella.exe (без Node.js)
Один файл `Stella.exe` (portable): скачал → запустил → подтвердил права администратора. Ничего ставить не нужно.
Собрать самому: `npm install`, затем `npm run dist` → `dist/Stella.exe`.

## Установка из исходников (Windows)
1. Скачать папку `agy-desktop`.
2. Запустить **`install.bat`** — поставит Node.js (если нет), зависимости и создаст ярлык «Agy Desktop» на рабочем столе (с флагом «Запуск от имени администратора»).
3. Дальше запускать через ярлык или `start.bat`.

Собирать ничего не нужно.

**Если не запускается:** запусти `debug.bat` — он откроет приложение без перезапуска от админа и покажет все ошибки, плюс выведет лог `%APPDATA%\agy-desktop\agy-desktop.log`. Если хочется один `.exe`: `npm run dist` → `dist/` (portable, сразу с `requireAdministrator`).

## Интерфейс
- `+` — прикрепить файлы (передаются как `@путь`)
- выпадающий список — модель (`agy models`, флаг `--model`)
- щит — режим разрешений: спрашивать / авто-правки (`--mode accept-edits`) / план (`--mode plan`) / полный автомат (`--dangerously-skip-permissions`)
- микрофон — диктовка `/voice`
- чёрная кнопка — `/voice live`; при наборе текста превращается в «отправить», во время ответа — в «стоп»
- слева — история чатов и рабочая папка агента; «Терминал» (Ctrl+`) показывает скрытый терминал

Отключить автоподъём прав (для отладки): переменная окружения `AGY_NO_ADMIN=1`.

## Браузер и управление экраном
Команды агента выполняются на изолированном рабочем столе `exebox` (баг agy на Windows), поэтому Stella работает мостом:
- **Браузер для агента** (переключатель слева): Stella открывает Chrome/Edge на вашем экране с отдельным профилем и подключает к `agy` MCP `chrome-devtools-mcp` (`~/.gemini/config/mcp_config.json`, разрешение `mcp(stella-browser/*)`). Агент управляет этим окном, вы видите всё вживую.
- **Управление экраном** (переключатель, по умолчанию выключен): агент делает скриншоты и управляет мышью/клавиатурой через команду `stella` (`%APPDATA%\agy-desktop\bin\stella.cmd`). Сверху появляется красная полоса, **Esc** — остановить. В поля пароля агент не печатает.
- Файлы/папки/ссылки агент открывает на вашем экране командой `stella open "<путь>"`.
