# ✦ Stella Cloud — сервер подписок

Сервер хранит **твои** ключи OpenRouter и ElevenLabs и раздаёт доступ пользователям приложения Stella по аккаунтам и тарифам. Ключи никогда не попадают в приложение.

## Запуск (Node.js 18+, без зависимостей)

```bash
cd server
cp .env.example .env     # впиши ключи и ADMIN_PASSWORD
node server.js
```

Или в Docker:

```bash
docker build -t stella-cloud .
docker run -d -p 8787:8787 -v stella-data:/data --env-file .env stella-cloud
```

Админ-панель: `http://IP-сервера:8787/admin`.

## Что умеет

- **Аккаунты**: регистрация/вход (scrypt), токены сессий, бан, смена пароля админом.
- **Тарифы**: Stella Free / Plus / Pro и свои — лимиты сообщений в день, символов озвучки в месяц, распознаваний в день, разрешённые модели (`*`, `openai/*`, точные id), управление ПК вкл/выкл.
- **Подписки**: выдать тариф на N дней вручную или выпустить **коды** (`PLUS-XXXXXX-XXXXXX`), которые пользователь активирует в приложении.
- **IP**: журнал IP каждого пользователя, **IP-замок** аккаунта (вход только с указанных адресов), блокировка IP целиком, лимит запросов в минуту с одного IP.
- **Прокси**: `/api/chat/completions` (OpenAI-совместимый стриминг с инструментами), `/api/models`, `/api/tts`, `/api/stt`, `/api/voices`.
- Журнал событий, статистика.

## Подключение приложения

В Stella: **Настройки → Stella Cloud** → адрес `http://IP:8787` → «Зарегистрироваться» или «Войти».
Чтобы приложение сразу знало адрес твоего сервера, создай файл `assets/cloud.json` перед сборкой:

```json
{ "url": "http://203.0.113.10:8787" }
```

## Безопасность

- Поставь HTTPS (например, Caddy или nginx перед сервером) — иначе пароли и токены идут открытым текстом. За прокси включи `TRUST_PROXY=true`, чтобы видеть реальные IP.
- Смени `ADMIN_PASSWORD`. База — `data/stella-cloud.json`, делай резервные копии.
