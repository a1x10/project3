# Stella Core

Сервер-мозг Стеллы (FastAPI + SQLite). Очки и телефон — клиенты этого сервера.

## Деплой на VPS
```
cp .env.example .env     # заполнить STELLA_API_KEY и OPENROUTER_API_KEY
docker compose up -d --build
```
Порт слушается только на 127.0.0.1:8000 — выставьте наружу через nginx/Caddy с HTTPS.
RAM: Whisper `base` для VPS 2 ГБ, `small` (~1–1,5 ГБ) для 4 ГБ+.

Все эндпоинты требуют `Authorization: Bearer $STELLA_API_KEY` (для SSE допустим `?key=`).

| Эндпоинт | Назначение |
|---|---|
| `POST /chat` `{text}` | диалог (текст) |
| `POST /voice` (файл `audio`) | Whisper -> диалог |
| `GET /events` | SSE-канал пушей: `hud speak action scan photo card suggest` |
| `POST /notify` `{app,sender,text,key}` | уведомление с телефона (важность, ночной режим) |
| `POST /alert` `{source,text,speak}` | алерты ботов, см. `scripts/send_alert.py` |
| `POST /vision/look` (файл `image`) | зрение без слов |
| `POST /vision/remember` (файл `image`) | визуальная память («где ключи?» — через `/chat`) |
| `POST /faces/identify` (файл `image`) | кто это (только база из `/admin`) |
| `GET /admin` | загрузка лиц, обязательна галочка согласия |
| `POST /home/act` | прямое управление домом (для кнопки «сделать» в `suggest`) |
| `POST /v1/chat/completions` | OpenAI-формат для AIUI Studio |

Событие `action` `{action:"reply", key, sender, text}` — телефон отвечает на уведомление `key`.

## Календарь
На ПК: `python scripts/google_auth.py credentials.json`, затем положите `google_token.json` в `data/`.

## Home Assistant
Заполните `HA_URL`, `HA_TOKEN`, `HOME_ALIASES`. Замки (`lock.*`) и `CONFIRM_ENTITIES` (стиралка)
выполняются только после подтверждения: сервер сам запоминает запрос и принимает `confirmed=true`
лишь в течение 2 минут после него.

## Заметки
- Лица считаются локально (OpenCV YuNet+SFace, модели скачиваются в `data/models` при первом запуске).
- Привычки: смена состояний пишется раз в минуту; ≥4 дней из 14 около одного времени (±20 мин) → предложение за 20 мин.
- Настоящее голосовое в WhatsApp и приложения телефона/очков — следующие этапы.

## Новое
- `GET /hud` — клиент очков (зелёный HUD, меню функций; ◀ ▶ ⏎ ▲ — тачпад, V — голос, C — камера).
- `GET /lab3d` — 3D-лаборатория: щипок рукой берёт деталь, две руки врозь/вместе — разбор/сборка (MediaPipe Hands).
  «Стелла, построй редуктор» → LLM генерирует детали, модель появляется на линзе.
- `/meeting/start|chunk|stop` — субтитры и подсказки (meeting/interview/exam), резюме в конце.
- `/voice/reply` — голосовой ответ: расшифровка на HUD → «отправляй» → телефон шлёт .ogg в WhatsApp.
- Стирка: `WASHER_*` в `.env`; режим по описанию («носки» → хлопок 60°, отжим 1200), запуск только после «да».
- Лица: только база из `/admin`. Поиска незнакомых людей по лицу в интернете нет намеренно.

## Только голос
HUD постоянно слушает микрофон. Фразы без обращения отбрасываются на сервере и не сохраняются.
- «Стелла, …» — команда. «Стелла» одна — сигнал + окно диалога 8 с.
- После ответа Стеллы ещё ~9 с можно отвечать без имени («да», «отправляй», «нет»).
- «Стелла, что это / кто это / запомни» — камера; «покажи сообщения / календарь / дом» — экраны;
  «включи совещание» / «Стелла, заверши совещание»; «построй редуктор» — 3D.
- Модель Whisper грузится при старте сервера и кэшируется в `data/hf`.

## Голос ElevenLabs
В `.env`: `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID` (Voices → Copy Voice ID), модель `eleven_flash_v2_5` (быстрая, русский).
HUD сам запрашивает `/tts` и играет mp3; фразы кэшируются в `data/tts`. Нет ключа или ошибка — обычный голос устройства.

## Sony Bravia
Телефон исполняет команды в домашней сети (сервер на VPS до ТВ не достаёт). На ТВ: Настройки → Сеть → Домашняя сеть →
IP-управление → Аутентификация «Обычная и Pre-Shared Key», задать PSK; «Простое IP-управление» вкл.; «Удалённый запуск» вкл.
IP и PSK вводятся в приложении Stella на телефоне. Команды: включить/выключить, громкость, mute, вход HDMI, приложения (YouTube, Netflix…), кнопки пульта.

## Обращение и быстрые команды
- Сильные формы имени (Стела, Эстелла, Стеллу, Stella…) ловятся в первых трёх и последних двух словах.
- Слабые искажения (стала, стол, стрела, сто, что, «из целое»…) — только как первое слово; мозг решает, была ли это команда
  (чужая фраза → молчание). Выключить: `WAKE_WEAK=0` в `.env`.
- «Громче / тише / без звука / громкость на 30» уходят на ТВ сразу, без мозга.
