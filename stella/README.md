# ✦ Stella Assistant

Живой 3D-ассистент для рабочего стола: VRM-аватар, который двигается, танцует, говорит голосом с движением губ и **управляет компьютером** по вашей просьбе. Два персонажа — **Стелла** и **Марк**.

## Скачать с GitHub

```bash
git clone -b claude/admiring-franklin-su9f89 https://github.com/a1x10/project3.git
cd project3/stella
npm install
npm start
```

Или без git: на странице репозитория выбери ветку `claude/admiring-franklin-su9f89` → **Code → Download ZIP**, распакуй и открой папку `stella`.

### Модели персонажей

В репозитории нет двух моделей: их лицензии запрещают распространение (у VRoid-модели Стеллы стоит `redistribution=disallow`, Nick — персонаж Scary Teacher 3D). Положи свои файлы сюда:

- `assets/models/stella.vrm` — модель Стеллы;
- `assets/models/nick.vrm` — чиби-модель Марка (или создай её из FBX: положи `Nick_T_pose.fbx` и текстуры в `tools/source/nick/` и выполни `node tools/convert-fbx-to-vrm.mjs`).

Без этих файлов приложение работает с процедурным Марком (`mark.vrm`). Свою модель можно также выбрать в программе: **Модель → Своя VRM-модель**.

## Быстрый старт

1. Установите [Node.js LTS](https://nodejs.org) (версия 18 или новее).
2. Запустите:
   - **Windows** — двойной клик по `start-windows.bat`
   - **macOS / Linux** — `./start-mac-linux.sh`

   Или вручную:
   ```bash
   npm install
   npm start
   ```
3. Создайте аккаунт и выберите ассистента: **Стелла или Марк**.
4. Откройте **Настройки** и вставьте ключи:
   - **OpenRouter** (мозг) — https://openrouter.ai/keys
   - **ElevenLabs** (голос и распознавание речи) — https://elevenlabs.io/app/settings/api-keys

Без ключа ElevenLabs ассистент говорит системным голосом. Без ключа OpenRouter работают анимации, реакции и ручные действия.

## Что умеет

| Раздел | Возможности |
|---|---|
| **Интерфейс** | Светлая тема по умолчанию (есть тёмные: Мел, Графит, Полночь) с рисунками на фоне, навигация сверху: Главная · Команды · Модель · Голос · ИИ · Компьютер · Настройки. Аватар стоит прямо в окне (справа или слева), внизу — статусы AI · STT · TTS |
| **Команды** | Свои фразы-триггеры → цепочка действий (сказать, анимация, сайт, поиск `{query}`, приложение, клавиши, терминал, медиа…). Работают мгновенно и без ИИ. Импорт/экспорт JSON |
| **Посадка** | Схвати аватара мышью и перетащи на любую панель — сядет на её край, болтает ногами и продолжает говорить. Двойной клик — вернуть на место. В режиме компаньона: опусти окно к панели задач — сядет на неё |
| **Мастерская → Реальный мир** | Персонаж **выходит из компьютера**. На телефоне (AR): отсканируй QR-код — он встаёт на твой пол или стол через камеру телефона, ходит туда, куда нажмёшь, садится на край стола, танцует и говорит синхронно с компьютером; с телефона можно писать ему сообщения. Через веб-камеру компьютера — стоит поверх видео с камеры |
| **Мастерская → Игры** | «Компаньон в игре»: аватар поверх любой игры бегает за курсором и комментирует экран. «Играть за меня»: ИИ сам играет по скриншотам (удержание клавиш, мышь). Стоп — Ctrl+Shift+F10 |
| **Мастерская → Агенты** | Подключение Google Antigravity: ассистент открывает её и отправляет задачу в чат агента |
| **Stella Cloud** | Свой сервер с подписками (папка `server/`): твои ключи на сервере, у пользователей — аккаунты, тарифы, лимиты, коды подписок, контроль IP |
| **Запуск** | Анимированный логотип → загрузка VRM-модели с прогрессом → приветствие персонажа → выезжает чат |
| **Аватар** | Дыхание, моргание, взгляд за курсором (даже за пределами окна), 20 анимаций: 3 вида танца, взмах, прыжок, поклон, хлопки, сердечко, кружение, смех, «победа» и др. Реакции на клики по голове/телу/ногам. Камера: во весь рост / по пояс / портрет, вращение мышью |
| **Эмоции** | Модель сама ставит теги `[happy]`, `[dance]`… — аватар меняет выражение лица и двигается |
| **Голос** | ElevenLabs TTS, озвучка по фразам во время генерации, **губы двигаются по реальному звуку** (анализ спектра → гласные а/и/у/э/о) |
| **Слух** | Кнопка микрофона (нажми и говори) и режим **«откликаться на имя»**: «Стелла, открой YouTube» / «Эй, Марк!» |
| **Компьютер** | 39 инструментов: терминал (PowerShell/bash), файлы, поиск файлов, запуск приложений, браузер и поиск, скриншоты (ассистент «видит» экран), мышь, клавиатура, окна, процессы, буфер обмена, громкость, медиа, таймеры, блокировка, выключение |
| **Безопасность** | 3 режима: «спрашивать всё», «только рискованное» (по умолчанию), «полная автономия». Опасные действия (`rm -rf`, `format`, выключение, системные папки) **всегда** требуют подтверждения. Удаление — только в корзину. Журнал всех действий |
| **Профиль** | Аккаунты с паролем (scrypt), выбор ассистента, статистика, «уровень близости», память о пользователе |
| **Инициатива** | Сам заговаривает после долгой тишины, засыпает, когда вас нет, и встречает при возвращении |
| **Компаньон** | Маленький аватар поверх всех окон |
| **Оформление** | 5 тем сцены, 8 акцентных цветов |

## Модели

- `assets/models/stella.vrm` — Стелла (VRM 0.x).
- `assets/models/nick.vrm` — Марк (чиби), сконвертирован из FBX скриптом `tools/convert-fbx-to-vrm.mjs`: объединённый скелет, гуманоидные кости, добавленный рот с гласными для липсинка.
- `assets/models/mark.vrm` — классический Марк, **сгенерирован процедурно** скриптом `tools/generate-mark.mjs` (VRM 1.0: скелет, 13 выражений лица, гласные для липсинка). Пересоздать: `npm run generate:mark`.
- Любую свою VRM можно подключить: **Настройки → Аватар → Своя VRM-модель**.

## AR на телефоне

- **Android**: Chrome + «Сервисы Google Play для AR» (ARCore) — полноценный AR: персонаж стоит на полу/столе и ходит по комнате.
- **iPhone**: Safari не поддерживает WebXR, поэтому режим «Через камеру» (персонаж поверх изображения камеры) или «Просто на экране».
- Телефон и компьютер должны быть в одной Wi-Fi сети. Сертификат самоподписанный — браузер предупредит, нажми «Дополнительно → Перейти на сайт». Если телефон не открывает страницу — разреши Stella Assistant в брандмауэре Windows (порт 8790).

## Платформы

- **Windows** — всё работает «из коробки» (PowerShell + WinAPI).
- **macOS** — дайте приложению доступ в *Системные настройки → Конфиденциальность → Универсальный доступ* и *Запись экрана*.
- **Linux** — для мыши/клавиатуры/окон установите `xdotool` и `wmctrl`.

## Структура

```
src/main/            процесс Electron: окна, IPC, хранилище, аккаунты
  llm.js             OpenRouter: стриминг, агентный цикл с инструментами
  voice.js           ElevenLabs: синтез, голоса, распознавание
  persona.js         характеры Стеллы и Марка, системный промпт
  computer/          инструменты ПК, политика безопасности, эмуляция ввода
src/renderer/        интерфейс
  js/avatar/         three.js сцена, загрузка VRM, процедурные анимации, эмоции
  js/core/           липсинк, теги, markdown, VAD, wake word, WAV
  js/ui/             чат, профиль, настройки, компьютер, голос, «присутствие»
tools/               генератор VRM-модели Марка
tests/               модульные и e2e тесты
```

Данные (аккаунты, чаты, зашифрованные ключи) хранятся локально в папке пользователя Electron (путь — в Настройках → Данные).
